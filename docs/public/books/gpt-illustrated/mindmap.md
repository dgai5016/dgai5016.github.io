- 词向量为语言模型提供高质量输入

### 基于Transformer的预训练模型

### 从初代GPT到GPT-4

- **涌现能力**：规模增大自然呈现新能力

## 第1章 N-Gram与Bag-of-Words

### 什么是语言模型
- 语言模型：估计**文本概率分布**的数学模型
- 判断文本序列在自然语言中的出现概率
- 可根据上下文预测**下一个最可能的词**
- 关注上下文中词与词的**相关性**

### N-Gram模型
- 灵感来自**香农熵**的词序列概率估计
- 概率模型：给定词序列算下一词概率
- 整序列联合概率太复杂，需**近似**
- 假设：`P(wₙ)` 仅依赖前 N-1 个词
- N=1/2/3 对应一元/二元/三元组
- 20世纪初已源于语言学家与密码学家

### N-Gram的构建过程
- 步骤1：文本切分成连续N词组合
- 步骤2：统计每个N-Gram的**词频**
- 步骤3：条件概率=N-Gram词频÷前缀词频
- 例：`P(爱|我)` = 3/10 = 30%
- 步骤4：迭代生成整句，算句子概率
- 句子概率 = 各条件概率**连乘**
- N-Gram是最早的**统计语言模型**

### 词与分词
- **Gram**：文本元素，可为词/字/子词
- **子词分词**：应对未登录词与拼写错误
- 子词切分减小**词汇表**，提升泛化
- `##` 标记子词是前缀/后缀非独立词
- **WordPiece**：贪婪/统计学最优切分
- **SentencePiece**：兼顾多个子词共性
- 分词产物即**Token**（模型处理单元）
- 英文用NLTK/spaCy，中文用**jieba**
- BERT用专属**Tokenizer**拆子词解生词
- 预处理另有清洗、去停用词、词性标注

### 实验：Bigram字符预测模型
- 实验：字符级Bigram能否生成连续文本
- 流程：语料→分词→词频→概率→生成
- 实验：`P(next|prefix)` 由词频比值算出
- 实验：贪心选概率最大词逐字生成
- 实验：输入前缀「我」生成完整句子
- 局限：只看前N-1词，难捕远处关系

### 词袋模型BoW
- 词袋把文本看作**一袋无序元素**
- 只统计**词频**，忽略词序信息
- 适合**文本分类、情感分析**场景
- 比较句向量**相似度**判断关联强弱

### 实验：词袋模型算文本相似度
- 流程：jieba分词→建词汇表→词袋向量
- 实验：句转向量，维度=词汇表大小
- **One-Hot**是单词成句时的词袋特例
- 余弦相似度：`A·B / (‖A‖ × ‖B‖)`
- 取值[-1,1]，越接近1越相似
- 看**角度**非距离，适合高维文本
- **欧氏距离**看实际距离，适合聚类推荐
- 实验：热力图显示语义近句相似度高

### 词袋模型的不足
- 缺陷1：**高维稀疏**向量，计算效率低
- 缺陷2：忽略**上下文**，无语义关系
- 改进：低维密集向量+上下文 → 词向量

### 小结与思考
- N-Gram用于**语言建模、生成、语音识别**
- N增大遭遇**数据稀疏**，性能下降
- 词袋用于**分类、情感分析、检索**
- 词袋不适合翻译、命名实体等词序任务
- 降维方案：**PCA**、**LSA**
- 思考：比较N=2/3/4对概率的影响
- 思考：**TF-IDF**解决停用词同权问题

## 第2章 Word2Vec与Embedding

### 词向量≈词嵌入
- **词向量**：词对应的数值向量表示
- **词嵌入**：词映射到向量空间的过程
- 两个术语通常可互换使用
- 语义相近的词余弦相似度高、距离近
- 训练后某维度可蕴含性别、年龄信息
- 把词与上下文信息「嵌入」向量中

### 词向量的习得方法
- 词向量靠算法从大规模语料库习得
- **Word2Vec** 是最著名的词向量算法
- 近朱者赤：词义由周围词推断
- 词与上下文一起学习，近义词靠近
- 用向量距离度量词间相似性

### Word2Vec：CBOW与Skip-Gram
- 2013年 Mikolov 团队于 Google 提出
- 分布式表示：1986年 Hinton 反向传播论文
- 分布式表示=离散符号映射连续向量空间
- **稀疏向量**：One-Hot、词袋，大量元素为0
- **稠密向量**：W2V，低维且信息更丰富
- **CBOW**：上下文词预测中心词
- **Skip-Gram**：中心词预测上下文词
- 滑动窗口 N 大小可调整
- 预测词只是手段，学词嵌入才是目标

### 实验：Skip-Gram构建神经网络
- **PyTorch**：张量计算 + 深度学习框架
- 动态计算图，灵活直观、生态丰富
- `nn.Module`：`__init__` 定层、`forward` 定传播
- 训练数据：(中心词, 周围词) 二元组
- 输入 One-Hot 编码，目标用词索引
- 索引作目标配合 `CrossEntropyLoss` 更高效
- 结构：两个无偏置线性层 9→2→9
- `input_to_hidden` 权重矩阵即词嵌入
- `softmax(xᵢ)=exp(xᵢ)/Σexp(xⱼ)` 归一化
- softmax 放大差异，概率分布更尖锐
- `CrossEntropyLoss` 内含 LogSoftmax+NLL
- 实验：1000轮训练损失 2.17→1.87
- 实验：二维图显示同类词向量相近

### 实验：CBOW模型实现
- 训练数据：(周围词列表, 中心词) 元组
- 隐藏层取多个周围词嵌入的平均值
- 实验：CBOW 同样习得可聚类词向量
- 按任务与数据特点选 CBOW 或 Skip-Gram

### 用 nn.Embedding 实现词嵌入
- **嵌入层**本质：可学习的权重查找表
- 参数：`num_embeddings`、`embedding_dim`
- 索引直接查行，免矩阵乘法更高效
- 免 One-Hot 编码，直接输入词索引
- 实验：嵌入层替换线性层仍学好词向量
- 权重形状 `[voc_size, embedding_size]`
- 真实语料词嵌入一般为几百维
- 词向量可作下游 NLP 任务输入特征
- GloVe、fastText 提供现成词向量

### 小结
- 词袋：计数稀疏，忽略词序与上下文
- W2V：学共现关系，低维稠密表达强
- W2V 是词嵌入基石，启发 GloVe、fastText
- 局限：静态词向量，难表一词多义
- 局限：无法处理未登录词
- W2V 非完善语言模型，未建模整句概率
- RNN/LSTM/Transformer 补足上下文建模

## 第3章 神经概率语言模型和RNN

### NPLM的起源
- 词向量模型缺句子级语义
- 无法解决一词多义问题
- 无法处理词汇表外未知词
- 2003年本吉奥论文首提神经语言模型
- N-Gram 靠共现统计，稀疏与长依赖弱
- **NPLM**：前 N-1 词预测第 N 词
- 用神经网络学习词汇概率分布
- 更擅长稀疏数据与长距离依赖
- 三层结构：输入层、隐藏层、输出层
- 矩阵 C：全词共享的查找表
- 隐藏层 tanh 学习词间复杂关系
- 输出 `P(wₜ=i|context)` 的概率分布

### 实验：NPLM的实现
- 实验：PyTorch 实现 NPLM 预测下一词
- 数据：前 N-1 词索引输入，末词为目标
- 流程：Embedding→展平→Linear+tanh→Linear
- 训练：交叉熵损失 + Adam 优化器
- 实验：5000轮训练损失 0.71→0.29
- 实验：「我 喜欢」成功预测「玩具」
- 贡献：开创性把神经网络引入 NLP
- 优点：自动学特征，免手工特征工程
- 优点：高效处理大规模语料、拟合强
- 不足：网络浅、窗口大小固定
- 不足：长距离依赖捕捉不足
- 不足：输出层=词表大小，训练效率低
- 不足：固定词汇表，未登录词无解

### 循环神经网络的结构
- **RNN** 核心：循环反馈隐藏状态保留信息
- 1986年 **BPTT** 算法奠定 RNN 基础
- 90年代提出 LSTM、GRU 等改进
- 2012年深度学习兴起，RNN 用于 NLP
- 隐藏状态：`hₜ = tanh(Wₕₕ·hₜ₋₁ + Wₓₕ·xₜ + bₕ)`
- 输出：`yₜ = softmax(Wₕᵧ·hₜ + bᵧ)`
- 各时间步共享权重，适配变长序列
- **BPTT**：沿时间步展开反向传梯度
- 缺陷：梯度消失与梯度爆炸
- **LSTM/GRU** 加门控，捕捉长依赖

### 实验：LSTM预测下一词
- 实验：LSTM 层替换线性层预测下一词
- 结构：Embedding→LSTM→Linear
- 仅取最后时间步隐藏状态做预测
- 输入门 `iₜ`、遗忘门 `fₜ`、输出门 `oₜ`
- 三门均用 sigmoid 算保留比例
- 细胞状态：`cₜ = fₜ·cₜ₋₁ + iₜ·gₜ`
- 隐藏状态：`hₜ = oₜ·tanh(cₜ)`
- LSTM 内部计算已被 PyTorch 封装
- `batch_first` 定输入形状批次在前
- RNN 中 `n_step` 不再影响网络结构
- NPLM 需展平嵌入，`n_step` 定输入大小
- RNN 的记忆能力长期是 NLP 的 SOTA
- 局限：顺序计算，难并行
- 局限：超长序列依赖仍难捕捉
- 局限：数据与任务规模化受限
- RNN 时代落地差：表达/数据/优化不足

### 小结
- NPLM：估计语言序列的概率分布
- W2V：CBOW/Skip-Gram 学词向量
- RNN/LSTM/GRU/Bi-LSTM 均源于 NPLM
- 自注意力+Transformer 开启新阶段
- 演进终点：BERT、GPT 预训练模型
- 下一站：Seq2Seq 与注意力机制

## 第4章 Seq2Seq编码器-解码器架构

### Seq2Seq架构
- 翻译/摘要/对话本质=**序列到序列**问题
- 类比电报电话的**通信模型**：编码-传输-解码
- 单一RNN兼任编解码→**信息损失**
- Seq2Seq分离编解码：各嵌独立RNN
- 2014年Sutskever等首提Seq2Seq
- **编码器**：输入序列→固定大小**上下文向量**
- **解码器**：上下文向量→逐时间步生成输出
- 解码是**自回归**的：上步输出作下步输入
- 本质：输入序列的**压缩**与**解压缩**
- 输入输出序列**长度可不等**→适合生成式NLP
- 编解码器可用RNN/LSTM/GRU或其他网络
- 可用**注意力机制**进一步增强性能

### 实验：构建简单Seq2Seq
- 实验：5句中英语料上训练Seq2Seq中译英
- 语料三列：源句、`<sos>`+英文、英文+`<eos>`
- `<sos>`/`<eos>`教会模型开始与停止生成
- **教师强制**：训练时解码器喂真实目标词
- 教师强制加速收敛但致**曝光偏差**
- **计划采样**：按概率改喂自身生成的词
- 编码器=嵌入层+RNN，解码器多一线性输出层
- 编码器`hidden`→解码器**初始隐藏态**（全句总结）
- 编码器`output`预留给**注意力机制**使用
- 实验：400轮训练损失降至0.006
- 实验：测试两句中文均翻译正确
- 测试时不教师强制，仅`<sos>`占位
- 输出长度绑定输入长度是简化做法
- 自回归生成应逐token输出直至`<eos>`
- **BLEU**指标：N-Gram精度+简短惩罚
- 可扩展：多层RNN、LSTM/GRU、双向RNN

### 小结
- 演进线：NPLM→RNN→LSTM/GRU→Seq2Seq
- NPLM局限：**上下文窗口固定**
- RNN缺陷：**梯度消失/爆炸**
- 门控单元（LSTM/GRU）缓解梯度问题
- Seq2Seq处理不等长序列，翻译摘要出色
- 短板：长序列压入定长向量→**信息损失**
- 解法：**注意力机制**给各token加权

## 第5章 引入注意力机制

### 点积注意力
- 动机：定长向量难捕捉动态上下文
- 注意力=对各位置分配不同**权重**选择性关注
- 最简单实现=**点积注意力**
- x1、x2特征维须一致，否则先线性变换
- 点积得原始权重，形状`(batch,seq1,seq2)`
- `torch.bmm`=批量矩阵乘法，`matmul`更灵活
- 点积即**相似度**得分，注意力核心思想
- 得分≠权重：归一化后才称权重
- `softmax`归一化：值0~1且每行和为1
- 公式：`softmax(xᵢ)=exp(xᵢ)/Σexp(xⱼ)`
- 权重对x2加权求和→输出形状同x1
- 输出=融入全序列上下文的**新x1**
- 注意力延展了**词嵌入**的内涵
- 实验：随机张量跑通四步注意力流程

### 缩放点积注意力
- 区别：归一化前将原始权重**除以缩放因子**
- 缩放因子=特征维度平方根`√d`
- 大点积→softmax陡峭区→**梯度消失**
- 缩放使softmax处于平缓区，训练稳定
- 流程：点积→÷√d→softmax→加权求和
- 实验：缩放后注意力分布更平缓

### 编码器-解码器注意力
- x1=**解码器**隐藏态，x2=**编码器**隐藏态
- 实为解码器对编码器的注意
- 输出**上下文向量**助解码器生成更准输出
- 实现：新增`Attention`类返回context与权重
- 解码器拼接`rnn_output`与`context`再进线性层
- Seq2Seq把编码器`output`传给解码器
- 实验：加注意力后翻译结果依然正确
- 实验：热力图可视化注意力权重
- 语料过少→权重过度集中（NLP对「自然」=1）

### 注意力机制中的Q、K、V
- **Query**查询：当前待处理的信息
- **Key**键：与Q算相似度→注意力权重
- **Value**值：按权重加权求和得输出
- 简例：Q=x1，K=V=x2
- Transformer中Q/K/V=同输入的不同**线性变换**
- K与V序列长须同，特征维可不同
- K与Q特征维须一致（点积要求）
- 编码器-解码器：Q=解码器态，K=V=编码器态
- 公式：`Attention(Q,K,V)=softmax(QKᵀ/√d)V`

### 自注意力
- x2换成x1：序列**自己注意自己**
- 同序列不同位置间建立依赖
- 实验：`x·xᵀ`→softmax→加权验证自注意力
- QKV版：x经三个线性层得Q/K/V再缩放点积

### 多头自注意力
- 对Q/K/V多次线性变换得多个**头**
- 各头并行做缩放点积注意力
- 拼接各头输出再做一次线性变换
- 优势：多**子空间**捕获多种特征
- 提升长距离依赖与语义层次捕捉
- 约束：`feature_dim=num_heads×head_dim`
- 实验：2头×2维跑通多头计算流程
- 常与前馈网络、**层归一化**组合成Transformer

### 注意力掩码
- 目的：注意力计算时排除不相关单词
- 不同于BERT完形填空式的训练掩码
- **填充掩码**：忽略`<pad>`冗余位防噪声
- 类似损失函数的`ignore_index`参数
- 加掩码矩阵→负无穷→softmax后≈0
- **后续掩码**（前瞻掩码）：解码器遮蔽未来
- 生成模型不能提前看到后续文本

### 其他类型的注意力
- **加性注意力**（Bahdanau）：全连接+tanh算分
- **全局注意力**：关注全部输入，成本高
- **局部注意力**：窗口内计算，分硬/软两种
- **自适应注意力**：动态权衡全局与局部
- **分层注意力**：词级→句级多层关注
- **因果注意力**：掩码防止未来信息泄漏
- 各机制可按任务需求选择组合

### 小结
- 注意力=对输入不同位置信息**加权**聚焦
- 加权和向量与解码器状态融合生成输出
- 缓解长序列与复杂上下文难题
- 机器翻译/摘要等NLP任务广泛受益
- 为**Transformer**时代开启新篇章

## 第6章 搭建GPT核心组件Transformer

### Transformer架构剖析
- 起源与动机
  - 2017 谷歌论文《Attention is All You Need》
  - 解决 Seq2Seq **长距离依赖**难题
  - RNN/LSTM 痛点：梯度消失/爆炸、难并行
  - 摒弃循环结构，靠注意力实现**并行计算**
- 编码器-解码器架构
  - 仍是 Seq2Seq 框架，内部实现全换新
  - 编码器转输入为表示，解码器生成输出
- 自注意力
  - 编码器/解码器每层各含自注意力子层
  - 四步：投影 QKV → 点积缩放 → softmax → 加权 V
  - 缩放因子 = **√dₖ**，防分数过大
- 多头自注意力
  - 灵感来自**多任务学习**
  - 各头独立参数，关注不同表示子空间
  - 输出拼接后经**线性层**整合
- 编码器-解码器注意力
  - Q 来自解码器上一层输出
  - K、V 来自编码器的输出
- 注意力掩码
  - **填充掩码**：屏蔽 `<pad>` 无意义位
  - **后续掩码**（前瞻掩码）：遮挡未来位置
  - 编码器只用填充掩码
  - 解码器需填充 + 后续双重掩码
  - 带后续掩码的注意力 = **因果注意力**
- 注意力提升性能三原因
  - 多层次多位置捕捉序列依赖
  - 表达能力强，适配序列到序列任务
  - 计算高度并行，训练提速
- 位置编码
  - 无循环结构，需额外注入位置信息
  - 偶数维 sin、奇数维 cos
  - 公式：`PE(pos,2i)=sin(pos/10000^(2i/d))`
  - 特点：周期性、平滑、保留相对位置
  - 自然数编码线性，难表达复杂位置关系
  - 替代方案：**可学习位置编码**
- 编码器结构
  - 词嵌入 + 位置编码相加后输入
  - 每层两单元：多头自注意力、前馈网络
  - **残差连接**：输入直连输出，稳梯度
  - **层归一化**：缓解内部协变量偏移
  - 二者合称 **Add & Norm** 层
  - FFNN：两线性层夹 ReLU 做非线性变换
- 解码器输入
  - 训练用目标真值 = **教师强制**
  - 推理用模型已生成的序列
  - 该输入序列也命名为 Output
  - **右移一位**：句首补 `<sos>` 起始符
  - 右移 + 后续掩码，并行下不看未来
- 解码器结构
  - 每层三单元：自注意力、enc-dec 注意力、FFNN
  - 自注意力只关注已生成位置
  - enc-dec 注意力引入编码器上下文
- 输出头与下游任务
  - 线性层映射到**词表大小**空间
  - softmax 转成概率分布（和为 1）
  - 机器翻译：贪婪/集束解码 + 交叉熵
  - 文本摘要：词表分布，集束或采样
  - 文本分类：换全连接层输出类别分布
  - 问答：两全连接层预测答案起止位置
  - 命名实体识别：逐位置交叉熵出标签

### Transformer代码实现
- 多头自注意力组件
  - 缩放点积：`Q·Kᵀ/√dₖ` → softmax → 乘 V
  - `masked_fill_(-1e9)` 屏蔽掩码位置
  - QKV 线性变换 + 重塑分出多个头
  - 多头拼接 → 线性层 → 残差 + 层归一化
  - 掩码沿头维度复制，每头同规则
- 逐位置前馈网络组件
  - Position-wise：各 token 独立同构处理
  - 升维至 2048 再降回嵌入维度
  - `nn.Conv1d`(核=1) 代替全连接省参数
  - 作用：增强表达、信息融合、层间传递
- 正弦位置编码表组件
  - 生成 `[位置数×嵌入维度]` 编码表
  - 角度 = `pos/10000^(2⌊j/2⌋/d)`
  - `from_pretrained(freeze=True)` 固定不训练
- 填充掩码组件
  - `<pad>` 编码为 0，`eq(0)` 定位填充位
  - 掩码 expand 成与注意力分数同形
  - 加到分数上，softmax 后权重趋 0
- 编码器层与编码器
  - 编码器层 = 多头自注意力 + 前馈网络
  - 编码器 = 词嵌入 + 位置编码 + 6 层堆叠
  - 输出维度保持 `[batch, seq_len, d_embed]`
  - 注意力权重保留头维度便于可视化
  - **BERT** 只用 Transformer 编码器
- 后续掩码组件
  - 源自教师强制：看真值但遮未来
  - `np.triu(k=1)` 上三角矩阵，上方为 1
- 解码器层与解码器
  - enc-dec 注意力：Q=解码器，K/V=编码器
  - 自注意力掩码 = 填充 + 后续掩码合并
  - enc-dec 掩码只含填充掩码
  - 三处注意力对比：编码器自注意力仅填充掩码
  - 解码器自注意力：填充 + 后续掩码
  - enc-dec 注意力：多头、仅填充掩码
- Transformer 整体组装
  - 十大组件从中心到外围逐个拼装
  - 编码器 + 解码器 + 线性投影层
  - 投影层输出目标词表大小 logits
  - softmax 已整合在交叉熵损失中

### 实验：完成翻译任务
- 数据准备
  - `TranslationCorpus` 类管理语料、字典、批次
  - 5 组中英例句的小型翻译数据集
  - 词表特殊符：`<pad>`=0、`<sos>`=1、`<eos>`=2
  - 序列填充至等长便于批处理
  - 测试时解码器输入仅 `<sos>` + `<pad>`
- 训练模型
  - 交叉熵损失 + Adam 优化器
  - 实验：训练 100 轮损失降至 0.000925
- 测试模型
  - 实验：一次前向翻译只对出首词后重复
  - 原因：未用**自回归**逐位生成输出
  - 改进方向：贪心/集束搜索逐步解码
- 结果反思
  - **奥卡姆剃刀**：简单任务简单模型优先
  - 复杂模型需复杂数据显优势

### 小结
- 架构地位
  - 自注意力取代循环，可并行处理变长序列
  - 捕捉长依赖 + 高效率 → 刷新 NLP SOTA
- 模型生态
  - 衍生 BERT、GPT、ChatGPT 等
  - 大规模**预训练 + 微调**再提性能
- 跨领域扩展
  - ViT：图像切块做图像分类
  - 也用于语音识别、推荐系统、强化学习

### 思考
- 组件构成与各自作用
- 三种注意力分别用在哪个组件
- 逐位置前馈为何共享参数
- enc-dec 掩码为何不需后续掩码
- 贪心逐位解码能否提升翻译

## 第7章 训练出你的简版生成式GPT

### BERT与GPT争锋
- Transformer 催生两大预训练模型：**GPT** 与 **BERT**
- BERT 预训练双目标：**MLM** 掩码猜词 + **NSP** 下一句预测
- MLM：随机遮 k% 词让模型预测，似**完形填空**
- BERT **双向**编码，同看上下文，擅长**理解任务**
- GPT **单向**语境，预训练任务是**语言建模**猜下一词
- GPT 自注意力加**后续掩码**，禁止偷看未来位置
- BERT 只用**编码器**，GPT 只用**解码器**（各半架构）
- 生成式语言模型是语言模型**原始状态**，猜词是创新
- N-Gram、Word2Vec、NPLM、Seq2Seq 本质皆生成式
- BERT 需任务微调；GPT 无须微调即可生成连贯文本

### GPT：生成式自回归模型
- **自回归**：基于已生成序列预测下一个元素
- 训练中自回归：预测下一词最小化**损失**，用**教师强制**
- 推理中自回归：种子文本逐词生成，新词回填再预测
- 三大解码策略：**贪婪搜索**、**集束搜索**、**采样**
- **生成式模型**建模数据分布，**判别式**学输入输出映射
- 神经网络形式属判别式，生成任务中行为如生成式
- 实验：贪婪解码器为 Transformer 补上自回归逐词翻译
- 每步取最高概率词，与已生成词一起再入解码器

### 实验：构建GPT模型并完成文本生成
- GPT＝解码器+投影层，复用 Transformer 五大组件
- 解码器层仅一个**自注意力**，省编码器-解码器注意力
- 两次**残差连接**+**层归一化**，稳定训练防梯度消失
- 解码器：词嵌入+位置编码相加，生成**后续掩码**
- N 层解码器层堆叠，投影层输出 **logits**
- 仅解码器结构适合无条件生成，非翻译/问答
- 语料库类：建词汇表、转索引、`<pad>` 补齐
- **向右位移**：输入 `seq[:-1]`，目标 `seq[1:]`
- 训练：**交叉熵**+Adam 跑 500 轮，损失降至 0.25
- 训练自回归靠右移目标+后续掩码+**并行计算**
- 推理：贪婪选词回填输入，遇 `<eos>` 停止
- 实验：输入 "Python" 续写出连贯数据科学句
- 贪婪解码高效，但易**局部最优**、词句循环重复

### 实验：用WikiText2训练Wiki-GPT
- WikiText2：维基百科精选文章，超 1 亿 **token**
- 实战重点：真实数据管线+模型评估，模型结构不变
- Torchtext 导入语料，`basic_english` 分词器
- `build_vocab_from_iterator` 建词汇表，共 28785 词
- Dataset 三方法：`__init__`/`__len__`/`__getitem__`
- WikiDataset：截 `max_len-2`，首尾加 `<sos>`/`<eos>`
- 源去 `<eos>`、目标去 `<sos>`，右移一位构样本
- DataLoader 分批，`collate_fn` 调 `pad_sequence` 补齐
- 训练循环：清梯度→前向→算损失→反向→更新
- 交叉熵设 `ignore_index`，`<pad>` 不计损失
- 评估：每轮在验证集算损失，保存**最小损失模型**
- `torch.save`/`torch.load` 存取，`.pt` 与 `.pth` 等价
- **集束搜索**：每步留前 K 候选，按累积概率排序
- 比贪婪更全局，代价是计算复杂度更高
- 实验：集束搜索续写 "my name"，后段胡说重复
- 结论：几万参数装不下亿级语料，需上亿至千亿参数
- 要对话能力须微调 LLaMA、OPT、GPT-2 等模型

### 小结
- GPT＝单向 Transformer 解码器，预训练猜下一词
- 架构三选择：BERT 仅编码器、GPT 仅解码器、T5 双塔
- 训练自回归：按下一词预测误差更新参数
- 预测自回归：生成词回填输入，循环至所需长度
- GPT-3 达 1750 亿参数，支持**零样本**/**少样本**
- ChatGPT＝大规模预训练+强化学习，专注对话

### 思考
- 练习：Transformer 改贪婪搜索自回归生成
- 练习：自建数据集改用集束搜索解码
- 练习：WikiText2 加测试集评估最终损失

## 第8章 ChatGPT基于人类反馈的强化学习

### 从GPT到ChatGPT
- NLP史：传统ML→**RNN**→**Transformer**→BERT/GPT
- 2017《Attention is all you need》奠基**Transformer**
- **GPT**(2018)：1.17亿参数，单向自回归
- **GPT-2**(2019)：15亿参数，生成优异引滥用忧
- **GPT-3**(2020)：1750亿参数，当时全球最大
- GPT-3靠**零样本/少样本学习**，多数任务免微调
- **伸缩定律**：性能随模型规模增长而提高
- 参数超**600亿**，推理能力开始显现
- ChatGPT=GPT-3.5+**指令调优** Instruction Tuning
- ChatGPT在**InstructGPT**上加安全合规考量
- **对齐**：让AI目标与人类价值观一致
- **RLHF**：人类偏好融入，输出友好安全
- **思维链CoT**：代码数据训练获得推理力
- **提示/指令模式**：NLP任务统一为提示形式
- **控制性能**：可控生成长度/风格/内容
- 微调中加入安全道德约束，减少偏见回复

### 实验：在Wiki-GPT上训练简版ChatGPT
- 范式：**预训练**学通用结构+**微调**适应对话
- 微调须用与预训练**相同分词器和词汇表**
- `chat.txt`：User行→输入序列，AI行→目标序列
- 序列首尾加`<sos>`/`<eos>`，补齐用`<pad>`
- `collate_fn`将批内序列补齐到最大长度
- 加载`best_model.pt`权重做二次训练
- 损失：交叉熵，`ignore_index=<pad>`
- 小数据集可**冻结底层**只调顶层，防过拟合
- 实验：微调后能简单对话，数据小则能力弱

### 实验：用Hugging Face GPT-2微调
- 实战不从0训练，用**Transformers**开源模型库
- 预训练模型与**分词器必须匹配**，否则词表冲突
- `gpt2`词表50257，eos/bos/unk均为`<|endoftext|>`
- GPT-2无pad符，手工设`<pad>`(ID 50256)
- 模型返回`CausalLMOutput`，核心取`logits`
- 其余属性：`past_key_values`/`hidden_states`/`attentions`
- 实验：微调后捕捉语料知识(天气→app/书→作者)
- 实验：BPE把未知词拆多token(Mockingbird拆3段)
- **预训练+微调**：省数据省算力仍获好性能

### ChatGPT的RLHF实战
- 训练三步之一：**SFT**监督微调得初始模型
- 之二：人工给答案排序评分，训练**奖励模型RM**
- 之三：RM打分+**PPO**算法继续优化
- 三步**循环迭代**，如左右互搏不断变强
- RL六要素：智能体/环境/状态/行动/策略/奖励
- ChatGPT映射：智能体=机器人，奖励=人类反馈
- **策略梯度**：调策略网络参数改进行动选择
- **PPO**(2017,Schulman)：稳定性好样本效率高
- PPO核心：**Clip**限制新旧策略概率比率
- 流程：收集经验→梯度优化→更新并重复
- 实战三步：反馈数据集→奖励函数→策略梯度
- 奖励=正确token得分÷非pad数÷max分
- 加权损失：`Σ(loss×(1−reward))÷N`
- 实验：训练中损失降，奖励0.16→0.67
- 实验：模型捕捉到高分回答中的信息

### 小结
- Wiki-GPT法：省时省资源，受限预训练领域
- GPT-2法：泛化更好，但需更多算力
- NLP趋势：模型压缩/可解释/多模态/个性化/隐私

- 已有惩罚促新主题，频率惩罚降重复

### 小结
- 调API=以参数传需求，GPT-4推理返方案
- **LangChain**：链/代理/提示模板的应用框架
- **LlamaIndex**：数据摄取/索引/查询框架
