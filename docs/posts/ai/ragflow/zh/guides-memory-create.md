# 记忆

本章介绍如何在 RAGFlow 中创建和配置记忆、查看和管理消息，以及在 Agent 中保存和检索记忆。记忆用于保存对话内容和 Agent 执行过程中生成的提取结果，帮助 Agent 在后续对话或任务中复用历史上下文。

## 创建记忆

1. 进入 **Memory** 页面。
2. 点击 **Create memory**。
3. 输入记忆名称。
4. 选择记忆类型、嵌入模型和大语言模型。
5. 点击 **Confirm** 创建记忆。
6. 确认后，进入记忆列表或详情页。
