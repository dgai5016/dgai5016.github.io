# 知识工件：知识工件的生成与管理

知识工件（Artifacts）由**知识编译（Knowledge Compilation）**生成。知识编译基于数据集中的文档和解析结果，进一步组织和处理知识内容，并根据所使用的知识编译模板生成相应的知识工件。不同的知识编译模板可以生成不同形态的知识工件，例如 **Wiki**、**Navigation** 和 **Graph**。生成的知识工件可在数据集中通过 **Artifacts**（知识工件）入口查看和浏览。

知识工件的创建和维护并不在 **Artifacts** 页面上完成。关于知识编译模板配置、知识工件的生成、更新、重新生成以及 **To Skill**（转为技能）操作，请参见 [**知识编译**](https://ragflow.io/docs/guides/file/link_dataset)。
