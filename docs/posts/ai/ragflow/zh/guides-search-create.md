# 创建搜索

搜索（Search）为知识库提供检索能力，帮助用户在已完成解析的知识库中快速找到相关内容。用户可以输入自然语言问题，并通过配置文档筛选、结果数量等选项缩小搜索范围。

搜索还支持 AI 摘要（AI Summary）、相关搜索（Related Search）、查询思维导图（Query Mind Map）等功能：这些功能会总结搜索结果、生成相关问题，并以思维导图形式呈现当前查询的主题结构，帮助用户进一步理解和探索知识内容。

以下各节介绍如何创建、配置和使用搜索。

1. 从顶部导航栏进入 **搜索** 页面。
2. 点击 **创建搜索**。
3. 为搜索输入名称并确认。
4. 打开新建的搜索，进入 **搜索设置**。
5. 在 **数据集** 下选择至少一个知识库，点击 **确定** 保存。
