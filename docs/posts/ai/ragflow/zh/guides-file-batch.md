# 批量移动与删除

文件列表左侧提供复选框。选中至少一个可操作的文件后，页面会显示批量操作栏，并显示已选文件的数量。

## 批量移动

1. 选中一个或多个文件。
2. 点击批量操作栏中的 **Move**（移动）。
3. 在目录树中选择目标文件夹。
4. 点击 **Save**（保存）保存移动结果。

## 批量删除

1. 选中一个或多个文件。
2. 点击批量操作栏中的 **Delete**（删除）。
3. 在确认对话框中核对要删除的文件数量。
4. 确认无误后提交删除。

某些系统文件夹、外部数据源文件或来自特殊来源的文件无法选中，或无法执行某些批量操作。这是权限与来源管控导致的正常行为。
