# 导入与导出 Agent

## 导入 Agent
- 首次导入：上传 JSON 文件，填写相应信息，拖拽或点击上传该文件，然后保存。

![从空白 Agent 页面导入 Agent](https://raw.githubusercontent.com/infiniflow/ragflow-docs/main/images/import_an_agent_1.jpg)
- 非首次导入：上传 JSON 文件，填写相应信息，拖拽或点击上传该文件，然后保存。

![从 Agent 页面导入 Agent](https://raw.githubusercontent.com/infiniflow/ragflow-docs/main/images/import_an_agent_2.jpg)

![上传 Agent JSON 文件](https://raw.githubusercontent.com/infiniflow/ragflow-docs/main/images/import_an_agent_3.jpg)
## 导出 Agent
打开一个 Agent，点击右上角的 **管理**，然后点击导出。

![导出 Agent](https://raw.githubusercontent.com/infiniflow/ragflow-docs/main/images/export_an_agent.jpg)
