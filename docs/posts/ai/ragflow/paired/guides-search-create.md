<template #zh>

<BiRow>
<template #en>

1. Go to the **Search** page from the top navigation bar.
2. Click **Create Search**.
3. Enter a name for the Search and confirm.
4. Open the newly created Search and go to **Search Settings**.
5. Under **Datasets**, select at least one knowledge base and click **OK** to save.

</template>
<template #zh>

1. 从顶部导航栏进入 **搜索** 页面。
2. 点击 **创建搜索**。
3. 为搜索输入名称并确认。
4. 打开新建的搜索，进入 **搜索设置**。
5. 在 **数据集** 下选择至少一个知识库，点击 **确定** 保存。

</template>
