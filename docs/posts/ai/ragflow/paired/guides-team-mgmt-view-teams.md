**Joined teams**（已加入的团队）列表显示当前用户已加入或被邀请加入的其他工作区。

<BiRow>
<template #en>

The list contains the following fields:

</template>
<template #zh>

该列表包含以下字段：

<BiRow>
<template #en>

| Field | Description |
| --- | --- |
| Name | The workspace owner's nickname. |
| Update date | The time when the membership record was last updated. |
| Email | The workspace owner's email address. |
| Action | Operations available for the joined team, such as accepting, declining, or leaving. |

</template>
<template #zh>

| 字段 | 说明 |
| --- | --- |
| Name（名称） | 工作区所有者的昵称。 |
| Update date（更新日期） | 成员关系记录最近一次更新的时间。 |
| Email（邮箱） | 工作区所有者的电子邮箱地址。 |
| Action（操作） | 已加入团队可用的操作，例如接受、拒绝或退出。 |

</template>
</BiRow>

<BiRow>
<template #en>

</template>
<template #zh>

你可以按所有者昵称或邮箱地址搜索已加入的团队，并按 **Update date** 排序。

</template>
