在 Mac 上，`Cmd + 空格` 唤出的是系统自带的聚焦搜索（Spotlight）。它能搜文件、开应用，但也就到此为止了：

- 想翻译一个单词，得开浏览器找词典网页
- 想找回五分钟前复制过的一段文字，发现剪贴板早就被覆盖了
- 想把一段 JSON 排版得好看点，又得开一个在线格式化工具

这些高频小需求，每一个都要单独开一个网页或软件。uTools 就是用来终结这种碎碎念的。

## 一、uTools 是什么

一句话：**uTools 是一个可以随时呼出的效率工具箱**，Windows、macOS、Linux 三端都有，官网是 [u.tools](https://u.tools)。

它的形态是一个全局搜索框——在任意界面按快捷键唤出，输入内容干活，干完按 `Esc` 走人，全程不打断当前工作。官方对它的定位是「插件化的生产力工具集」：本体很小，能力全靠插件撑起来。

**核心能力：**

- **全局呼出**：任意界面一键唤出搜索框，即用即走
- **插件生态**：数百款插件——翻译、剪贴板历史、图床、密码管理、JSON 格式化、颜色吸取、hosts 编辑……常用的效率需求基本都有人做好了
- **关键字直达**：输入 `翻译 hello` 回车，直接进翻译插件出结果，不用先打开插件再粘贴
- **应用与文件搜索**：Spotlight 的本职工作（搜应用、搜文件、简单计算）它也能干
- **账号同步**：登录账号后，插件和配置可以在多台设备间同步

日常使用免费，少数高级功能属于付费的专业版，入门阶段完全用不着操心。

**安装**

方式一：Homebrew（推荐）

```bash
brew install --cask utools
```

方式二：官网下载

去 [u.tools](https://u.tools) 下载 dmg，拖进「应用程序」即可。

装好后打开一次，uTools 会常驻菜单栏。macOS 上默认的呼出快捷键是 `Option + 空格`，先按一下试试。

## 二、用 Cmd + 空格 唤出 uTools（替换 Spotlight）

`Cmd + 空格` 是整个 Mac 上最顺手的键位——拇指和食指自然落下就是它，多年的肌肉记忆已经刻进骨子里。默认它属于 Spotlight，但 Spotlight 会干的活（搜应用、搜文件、算数），uTools 都能干；uTools 会干的活（翻译、剪贴板、格式化），Spotlight 干不了。

所以这个最好的键位，应该交给 uTools。整个替换分两步：先把 `Cmd + 空格` 从系统手里释放出来，再设给 uTools。

### 第一步：释放系统的 Cmd + 空格

`Cmd + 空格` 默认被聚焦搜索（Spotlight）占用，先把它让出来：

1. 打开 **系统设置 → 键盘 → 键盘快捷键…**
2. 在左侧分类列表选择 **聚焦**
3. 找到 **「显示聚焦搜索」**，取消勾选（或者点后面的快捷键，改成一个你不常用的组合，比如 `Ctrl + Option + 空格`）

取消勾选后，Spotlight 就不再响应 `Cmd + 空格` 了。想反悔随时回来重新勾上，没有任何副作用。

### 第二步：把 Cmd + 空格 设给 uTools

1. 按 `Option + 空格` 唤出 uTools（改键完成之前还是老快捷键），此时 uTools 处于前台
2. 直接按 `Cmd + ,` 打开设置页——这是 macOS 通用的「打开偏好设置」快捷键，uTools 也遵守它
3. 在 **「使用偏好」** 小节里找到 **「搜索框快捷键」**（默认显示 `Option + 空格`）
4. 点进快捷键输入框，按下 `Cmd + 空格`，立即生效

### 验证

随便切到任意一个应用窗口，按下 `Cmd + 空格`——弹出来的应该就是 uTools 的搜索框。再输入 `翻译 hello` 试试，如果直接出了翻译结果，说明整条链路都通了。
