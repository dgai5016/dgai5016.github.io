第2章攒下了词向量，但语言模型还停在数频次的 N-Gram。本章神经网络正式接管语言建模：先看 2003 年开山的 NPLM，再看为「记忆」而生的 RNN 与 LSTM。解读按「问题 → 概念 → 实验 → 误区 → 自测」五段走。

## 一、本章解决什么问题：会认词，还不会造句

第2章结束时的局面有点尴尬：Word2Vec 能把每个词变成向量，但原书点出它只关注词的局部语义——句子级语义捕捉不到；一词多义无解（中文「拍」可褒可贬，英文「Apple」是水果还是公司全看上下文，而 Word2Vec 只能給每个词一个固定向量）；词汇表外的词直接抓瞎。另一边，N-Gram 语言模型靠统计共现频率干活，原书明说它在稀疏数据和长距离依赖面前力不从心。

本章主角 NPLM（Neural Probabilistic Language Model，神经概率语言模型）把两件事接在一起：它和 N-Gram 干同样的活——用前 N-1 个词预测第 N 个词，但把「查频率表」换成「查向量、过神经网络」。原书的评价很高：自此深度学习登上了 NLP 的舞台。

## 二、核心概念通俗解读

### NPLM：三层楼加一本共享字典

NPLM 出自 2003 年约书亚·本希奥（Yoshua Bengio）团队的论文《A Neural Probabilistic Language Model》，结构就三层：

1. **输入层**：核心是矩阵 C。术语白话：论文称之为 table look-up「查找表」——一本字典，输入词的索引（或 One-Hot 编码）进来，查表得到它的词向量。关键是 C 在所有词之间**共享**：不管句子里哪个词都用同一本字典查，原书说这有助于减少参数数量、提高泛化能力。
2. **隐藏层**：把几个上下文词的向量拼起来，线性变换后过 tanh 激活（2003 年 ReLU 还不流行；原书还提到论文特别注明这部分计算量大——当年算力太弱）。
3. **输出层**：全连接层给词汇表里每个词打分，softmax 变成概率分布，输出 P(wₜ=i|context)——给定上下文，下一个词是词表中第 i 个词的概率。

换个说法理解整栋楼：输入层「查字典」，隐藏层「琢磨这几个词搁一起是什么意思」，输出层「给每个候选词下注」。

### RNN：边读边记的便签

NPLM 有个天生的紧箍咒：窗口固定，n_step=2 就永远只看两个词。RNN（Recurrent Neural Network，循环神经网络）的解法是给网络加「记忆」：每个时间步（处理一个 token 就是一步）读入当前词 xₜ，结合上一步的隐藏状态 hₜ₋₁，更新出新的隐藏状态：

`hₜ = tanh(Wₕₕ·hₜ₋₁ + Wₓₕ·xₜ + bₕ)`

逐个符号说：h 是隐藏状态——类比一张**边读边记的便签**，读到第 t 个词时，便签上沉淀着前 t 个词的摘要；Wₓₕ 是「新词写上便签」的权重，Wₕₕ 是「便签旧内容往下传」的权重，bₕ 是偏置，tanh 把数值压回 -1~1。输出再由便签经线性变换加 softmax 得到：`y_t = softmax(W_hy * h_t + b_y)`。

妙处在**权重共享**：每个时间步用的是同一套 W，序列多长都行——正好拆掉 NPLM 的固定窗口。

### BPTT：把循环摊平了往回传

RNN 的训练用 BPTT（Backpropagation Through Time，通过时间反向传播），1986 年由鲁梅尔哈特（Rumelhart）等人提出。白话：它是针对时间结构数据的反向传播——先把循环按时间步摊成一条长链，再一步一步往回传。原书列的步骤：各时间步算损失再求和 → 链式法则把梯度沿时间步传回去 → 用梯度下降或 Adam 更新参数。

### 梯度消失与爆炸：传话游戏越传越走样

原书指出，RNN 训练会遇到梯度消失和梯度爆炸，导致长距离依赖很难学到。展开说（换个说法）：梯度沿时间链往回走，每过一步都要乘一次系数——系数连乘小于 1，走几十步后趋近于零。注意「梯度消失」不是梯度这个机制消失了，而是**序列开头的词几乎收不到学习信号**，早期信息学不进去；反过来系数连乘过大就是梯度爆炸，训练直接崩掉。为了治这个病，90 年代的学者造出了带门控的 LSTM 和 GRU。

### LSTM：给记忆装三只阀门

LSTM（Long Short-Term Memory，长短期记忆网络）在 RNN 骨架上加了条「细胞状态」cₜ——一条专门运输长期记忆的传送带——和三只 sigmoid 阀门（sigmoid 输出 0~1，正好当阀门开度用）。原书给的三个门都由当前输入 xₜ 和上一步隐藏状态 hₜ₋₁ 算出：

- **输入门 iₜ**：新信息**写入**记忆的比例；
- **遗忘门 fₜ**：旧记忆**保留**的比例，原书明说 fₜ 为 0 就是把历史全忘掉；
- **输出门 oₜ**：记忆对外**曝光**的比例。

记忆传送带的更新公式是全章最值得背的一行：

`cₜ = fₜ·cₜ₋₁ + iₜ·gₜ`

逐符号讲：cₜ₋₁ 是上一步的旧记忆；fₜ 是旧记忆的保留系数；gₜ 是细胞候选状态——由当前输入和上一步隐藏状态经 tanh 算出的「新内容草稿」；iₜ 是这份草稿的写入系数；两项相加得新记忆 cₜ。代入一组数字走一遍（数字是演示用的编造值，只为看清结构）：旧记忆 cₜ₋₁=1，遗忘门开 fₜ=0.9，新草稿 gₜ=2，写入门只开 iₜ=0.1，则 cₜ = 0.9×1 + 0.1×2 = 1.1——记忆以旧为主、小幅吸收新意。最后记忆对外露多少，由 `hₜ = oₜ·tanh(cₜ)` 决定。

换个说法总结：RNN 的便签每一步都被整体重写，LSTM 的传送带每步只被两只阀门微调——长期信息有了专线。

## 三、书中实验讲解

### NPLM 实验：三句话养一个语言模型

语料只有三句：「我 喜欢 玩具」「我 爱 爸爸」「我 讨厌 挨打」，词汇表 7 个词。造数据很直白：每句前 n_step=2 个词做输入，最后一个词做目标——「我 喜欢」→「玩具」。模型结构打印出来一目了然：Embedding(7, 2)（就是查找表 C）→ Linear(4, 2) 加 tanh（4 = 2 个词 × 2 维嵌入，展平拼接）→ Linear(2, 7)（输出 7 个词的得分）。forward 里最关键的一行是 `X = X.view(-1, n_step * embedding_size)`——把两个词的嵌入拼成一个大向量，这正是「窗口固定写进结构」的代码证据。

训练用交叉熵损失 + Adam（学习率 0.1），跑 5000 轮，损失一路走低：0.711 → 0.518 → 0.383 → 0.327 → 0.285。预测时取概率最大的词（`model(input_batch).data.max(1)[1]`），模型稳稳给出「我 喜欢」→「玩具」、「我 爱」→「爸爸」。

原书同时泼了冷水：NPLM 历史意义大于实力——结构浅、窗口固定、捕捉不到长距离依赖、输出层与词表同大导致训练效率低、词表固定处理不了未登录词。

### LSTM 实验：只换一个层

第二场实验改动小得惊人：数据和训练参数全不动，只把第一个线性层换成 `self.lstm = nn.LSTM(embedding_size, n_hidden, batch_first=True)`，结构变成 Embedding(7, 2) → LSTM(2, 2) → Linear(2, 7)。取结果只看最后一步：`output = self.linear(lstm_out[:, -1, :])`——前两个词经 LSTM 逐步消化，用最后一步的隐藏状态做预测。训练同样 5000 轮、损失逐步下降（原书本节印出的损失数值与 NPLM 完全相同，应是排版沿用；预测同样是「我 喜欢」→「玩具」这类正确接龙）。咖哥也坦承：玩具任务上改进不会显著，但面对更复杂的真实语言任务时，LSTM 通常优于简单线性模型。

有两处本质区别被特意点破：① 代码里看不到 hₜ 的公式，因为细节封装进了 PyTorch 的 LSTM 层，一行 `lstm_out, _ = self.lstm(X)` 背后是逐时间步的门控运算；② **n_step 从网络结构里消失了**——NPLM 中它决定第一个线性层的输入尺寸（n_step×m），RNN 中词嵌入直接进 LSTM、无需展平，序列多长都不改结构。所以别看改动小，这个模型本质上已经不是 NPLM。

## 四、易错点/误区

先上两张对比表。

| | RNN | LSTM |
|---|---|---|
| 记忆载体 | 隐藏状态 hₜ，每步整体重写 | 细胞状态 cₜ 专线运输，隐藏状态只管输出 |
| 门控 | 无 | 输入、遗忘、输出三只阀门 |
| 长距离依赖 | 易梯度消失/爆炸，学不到 | 门控让旧记忆走「加法」更新，好得多 |
| 关系 | 基础款 | 广义上也是 RNN，是带门控的改进版 |

| | 普通反向传播 | BPTT |
|---|---|---|
| 对象 | 层与层堆叠的普通网络 | 先按时间步展开的循环网络 |
| 传的方向 | 从输出层往输入层 | 从后面的时间步往前面传 |
| 本质 | 链式法则 | 还是链式法则，只是先摊开再求导 |

再纠四个常见误会：

1. **三门背串**：输入门管「新信息写多少」、遗忘门管「旧记忆留多少」、输出门管「记忆说多少」——写入、保留、曝光各管一段，别按字面把输入门当成「输入数据的门」。
2. **梯度消失 ≠ 梯度真的没了**：是连乘让早期时间步收到的梯度趋近零，开头的信号学不到；它和梯度爆炸是同一根源（连乘）的两个方向。
3. **RNN 的头号短板是算不快**：原书列的第一条局限是顺序计算——上一步没算完，下一步不能开工，无法并行。小冰问「ChatGPT 是不是也用了 RNN」，咖哥直接说不对；Transformer 的核心论文《Attention is All You Need》的主要思路就是摒弃 RNN。
4. **NPLM 的窗口固定是「结构级」的**：n_step 写死在线性层的输入尺寸里，不是随手可调的超参；RNN 靠权重共享天然吃变长序列。另一个小观察：原书用 `set()` 去重生成词汇表，每次运行的词→索引映射可能不同，自己复现时索引和书里对不上属正常现象。

## 五、复习自测

先自己答，再看参考答案。

1. NPLM 与 N-Gram 的相同点和本质区别分别是什么？
2. 查找表矩阵 C 为什么要在所有词之间共享？好处是什么？
3. 写出 RNN 隐藏状态的更新公式，并说明每个符号的含义。
4. LSTM 三个门各控制什么？公式 `cₜ = fₜ·cₜ₋₁ + iₜ·gₜ` 里每一项是什么？
5. 为什么说 LSTM 实验中「n_step 消失了」？这反映了 NPLM 与 RNN 的什么本质区别？

**参考答案**

1. 都是用前 N-1 个词预测第 N 个词的语言模型；区别是 N-Gram 靠统计共现频率，NPLM 用神经网络学习概率分布，更能处理稀疏数据和长距离依赖。
2. 所有输入词用同一个 C 查词向量；减少模型的参数数量，提高泛化能力。
3. `hₜ = tanh(Wₕₕ·hₜ₋₁ + Wₓₕ·xₜ + bₕ)`：h 是隐藏状态（便签），xₜ 是当前输入，Wₓₕ 是新词写入便签的权重，Wₕₕ 是上一步便签传递下去的权重，bₕ 是偏置，tanh 把结果压到 -1~1。
4. 输入门 iₜ 控制新信息写入比例，遗忘门 fₜ 控制旧记忆保留比例（为 0 即全忘），输出门 oₜ 控制记忆输出比例；cₜ₋₁ 是旧记忆，gₜ 是当前算出的候选新内容，fₜ·cₜ₋₁ 是保留的部分，iₜ·gₜ 是写入的部分，相加得新记忆 cₜ。
5. NPLM 中 n_step 决定第一个线性层的输入大小（n_step×m），序列长度被写死进结构；RNN 的词嵌入直接进 LSTM，靠各时间步权重共享处理任意长度序列，网络结构不随序列长度改变。

走完本章，神经网络全面接管了语言建模，但 RNN 顺序计算的基因注定它撑不起后来的 ChatGPT。下一章的 Seq2Seq 将先解决「序列进、序列出」，再往后，注意力机制就要登场了。
