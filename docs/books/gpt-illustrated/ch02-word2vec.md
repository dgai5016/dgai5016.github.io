第1章的词袋模型已经能把文本变成数字，但那串数字只「认得」词，不「理解」词。本章的 Word2Vec（W2V）要给每个词发一张语义身份证：一组低维坐标，意思相近的词住得近。解读仍按「问题 → 概念 → 实验 → 误区 → 自测」五段走。

## 一、本章解决什么问题：点名册上没有语义

第1章留下了两大缺陷，本章开头的小结说得直白：

**其一，高维稀疏。** 词袋和 One-Hot 向量的长度等于词汇表大小，绝大多数位置是 0。原书原话：词袋模型就是一种稀疏向量表示，而 One-Hot「更是稀疏了，每一个编码中，都有大量的 0，而只有一个 1」。真实词汇表动辄上万词（《辞海》词条近 13 万，书里举的例子），一个词就要占上万维的坑。

**其二，没有语义。** 词袋只数频率，忽略了顺序和上下文，「不太善于捕获单词之间的语义关系」。在词袋眼里，「猫」和「狗」的距离，与「猫」和「微积分」的距离一样远——它是一本点名册，谁来了记一笔，谁跟谁是一伙的，完全不知道。

本章药方是 Word2Vec：用一个小神经网络从语料中为每个词学出一个**低维、稠密、带语义**的向量。原书有张图很直观：如果语料里「小冰」「小雪」总跟「女生」一起出现，训练后某个维度就会蕴含性别信息；总跟「年轻」一起出现，另一个维度就蕴含年龄信息。词和它的上下文都被「嵌入」了向量表示——这就是「词嵌入」名字的由来。

## 二、核心概念通俗解读

### 词向量 ≈ 词嵌入

原书明确说这两个术语通常可互换，硬要区分的话：**词向量**偏指结果——「'cat' 的词向量是一个 300 维的向量」；**词嵌入**偏指过程和方法——「用 Word2Vec 算法生成词嵌入」。效果上，语义相近的词在向量空间里余弦相似度高、距离近。

### 稀疏 vs 稠密：从点名册到身份证

| | 稀疏向量 | 稠密向量 |
|---|---|---|
| 元素构成 | 大部分为 0 | 大部分非零 |
| 维度 | 高（等于词汇表大小） | 低（几十到几百维） |
| 代表 | One-Hot、词袋 | Word2Vec |
| 能力 | 只记「有没有/几次」 | 捕捉语义和语法关系 |

本章的目标，用原书的话说，就是把稀疏向量「压缩成更具有表现力的低维稠密向量」。

### 近朱者赤：语义从共现中来

词的这些「维度」从哪来？不是人手工标注的，是从语料库中习得的。Word2Vec 的核心思想，原书给的比方就是「近朱者赤，近墨者黑」，英文谚语「看一个人跟谁交往，能得知他的品性」——一个词的含义可以根据它周围的词推断出来。换个说法：词向量是词的社交坐标，常共现的词住得近。训练时把一个词和它周围的词放在一起学，相似语义的词自然靠拢。

历史脉络书上三句话带过：分布式表示的思想可追溯到 1986 年辛顿等人的反向传播论文；90 年代本吉奥等人把它推向语言模型；2013 年 Google 的米科洛夫团队推出 Word2Vec，高效到能处理大规模语料，从此成为词嵌入领域的基石。

### CBOW 与 Skip-Gram：方向相反的孪生结构

Word2Vec 通过训练一个神经网络来学词嵌入，模型任务是「基于上下文预测目标词，或基于目标词预测上下文」，于是有两种方向相反的实现：

| | CBOW（连续词袋） | Skip-Gram（跳字） |
|---|---|---|
| 输入 | 周围词（多个） | 中心词（一个） |
| 预测 | 中心词 | 周围词 |
| 训练数据 | （周围词列表， 中心词） | （中心词， 周围词）成对出现 |
| 隐藏层 | 周围词嵌入取平均 | 中心词嵌入直通 |
| 白话 | 完形填空：看上下文猜空格 | 看一个人猜他的朋友圈 |

原书特别提醒：这两个网络都是浅层神经网络，「严格说还称不上深度学习」，滑动窗口大小 N 可以调整。

### softmax：把九个分数变成一张概率表

网络输出的是每个词的原始得分，要变成概率得靠 softmax，公式即 `softmax(xᵢ) = exp(xᵢ) / Σⱼ exp(xⱼ)`。拿书中训练过程真实打印的一次输出手算：9 个得分中最高的是 2.5058，次高 0.5782，最低 -0.8938。指数化后约为 12.25、1.78、0.41，全部 9 项加起来约 19.03。相除：最高分拿到 12.25/19.03 ≈ **64%**，次高只剩约 9%，最低约 2%。这就是原书说的 softmax 特性——「放大输入向量中的差异，使得概率分布更加尖锐」。

配套的 CrossEntropyLoss（交叉熵损失）白话：衡量模型分给正确答案的概率有多大，概率越高损失越小。换个说法帮它落地：正确答案若拿到 0.64 的概率，损失约 `-ln(0.64)` ≈ 0.45；若只拿到 0.02，损失约 3.9——模型越看不上正确答案，罚分越重。

### nn.Embedding：一张查找表

本章先用线性层（nn.Linear）实现，最后升级为嵌入层（nn.Embedding）。二者本质一样，都是通过调整层内参数来习得词向量。妙处在于：One-Hot 向量乘权重矩阵，数学上恰好等于「抽出矩阵中对应的那一行」——既然如此，不如直接查表。嵌入层的好处原书列了三条：代码更简洁；效率更高（不做矩阵乘法，直接从权重矩阵查行）；更容易训练（输入直接用单词索引，省掉 One-Hot 编码）。实验里嵌入维度取 2 只是为了画图，BERT、GPT 这类模型要学几百维（128、256、512 等）才能装下更丰富的语义。

## 三、书中实验讲解

### Skip-Gram 实验：9→2→9 的小网络

语料 5 个短句：Kage is Teacher / Mazong is Boss / Niuzong is Boss / Xiaobing is Student / Xiaoxue is Student。词汇表 9 个词。麻雀虽小角色齐全——两个 Boss、两个 Student、一个 Teacher，正好检验「同类词会不会聚拢」。

六步流程：① 建语料和词汇表（set 去重，注意 set 无序）；② 以 window_size=2 生成 Skip-Gram 数据，每个中心词配上周围词成二元组，共 30 对，如 ('Kage', 'is')、('Kage', 'Teacher')；③ 输入做 One-Hot 编码（9 维），目标只存周围词的索引；④ 定义网络，核心两行：

```python
self.input_to_hidden = nn.Linear(voc_size, embedding_size, bias=False)
self.hidden_to_output = nn.Linear(embedding_size, voc_size, bias=False)
```

结构即 9→2→9：One-Hot 进来，压到 2 维嵌入，再映射回 9 个得分。⑤ 训练：学习率 0.001，SGD 优化器，CrossEntropyLoss，1000 轮。损失从第 100 轮的 2.17 缓降到第 1000 轮的 1.87——语料太小，降幅温和，但方向正确。⑥ 提取词向量：`skipgram_model.input_to_hidden.weight[:,idx]`——**input_to_hidden 权重矩阵的每一列，就是一个词的嵌入**。

结果最有趣：Xiaobing [-1.36, -2.13] 和 Xiaoxue [-1.37, -2.14] 几乎重叠；Niuzong [0.82, -0.62] 和 Mazong [0.82, -0.62] 几乎重叠；Boss [2.92, -0.42] 自成一角。画在二维平面上，同类词明显聚拢。没人告诉模型谁是老板谁是学生，它只从「谁和谁搭配」中自己学了出来——「近朱者赤」就这么落了地。原书还借小冰之口点了个题：光看两个数字看不出相似，画出来才直观，这正是嵌入维度取 2 的用意。

### CBOW 实现：只改两处

结构与 Skip-Gram 同款 9→2→9，区别一在数据：多个周围词打包对应同一个中心词，如 ('Kage', ['is', 'Teacher'])；区别二在前向传播多一步取平均——`hidden_layer = torch.mean(embeddings, dim=0)`，把几个周围词的嵌入向量求平均作为隐藏层，再预测中心词。这就是表中「CBOW 隐藏层取平均」的出处。

### nn.Embedding 替换线性层

第三版改造把输入层换成 `nn.Embedding(voc_size, embedding_size)`，输入直接用中心词索引 `torch.tensor([word_to_idx[center_word]])`，One-Hot 彻底退场；取词向量也从 `weight[:,idx]`（取列）改成 `weight[idx]`（取行），因为嵌入层的权重形状是 [词汇表大小, 嵌入维度]，一行一词。跑起来同样能学出词向量。

## 四、易错点/误区

**方向记反。** CBOW 是「周围→中心」（Context 为主、 Bag 装周围词），Skip-Gram 是「中心→周围」（跳出去找邻居）。记法就抠字面：CBOW 本质还是「词袋」思路——把周围一袋词拢起来猜一个词。

**预测词只是手段，嵌入才是目的。** 原书强调了两遍：预测具体的词并不是 Word2Vec 的目标，真正目标是学习词嵌入；训练完直接从权重里提取词向量，预测头用完即弃。小冰的总结很精彩：从预测词的角度看，它与 N-Gram 同类，都是语言模型；从「提取嵌入权重做向量表示」的角度看，它与词袋同类，都是把词变成向量。

**嵌入存在哪个权重里。** 在 input_to_hidden（输入到隐藏层）的权重矩阵里；hidden_to_output 只是预测的配套件。取法注意版本差异：线性层版取**列**（`weight[:,idx]`），嵌入层版取**行**（`weight[idx]`）——两版权重矩阵的形状排布不同，混用会取错词。

**没写 softmax ≠ 没用 softmax。** PyTorch 的 CrossEntropyLoss 内部结合了 LogSoftmax 和 NLLLoss，概率转换已隐含在损失函数里。同理，目标词传索引而非 One-Hot，也是 CrossEntropyLoss 的设计：只需正确类别的索引，不必处理高维稀疏向量。

**别忘了局限。** Word2Vec 是静态词向量，一词一个固定向量，多义词无法区分；训练时没见过的词也给不出向量。且它本身不是完善的语言模型——没有对整个句子的概率分布建模，这要留给后来的 RNN、LSTM 和 Transformer。

## 五、复习自测

先自己答，再看参考答案。

1. 词袋/One-Hot 表示的两大缺陷是什么？Word2Vec 分别拿什么对策？
2. CBOW 和 Skip-Gram 的输入与预测方向有何不同？各自的训练数据长什么样？
3. 训练完成后，词向量从网络的哪里取出？线性层版与嵌入层版的取法差在哪？
4. 书中代码没有显式调用 softmax，概率转换发生在哪里？目标词为什么传索引而不是 One-Hot？
5. 为什么说「预测词只是手段」？Word2Vec 的最终产物是什么，能用在哪些下游任务上？

**参考答案**

1. 高维稀疏（长度等于词汇表大小、大量 0）与无语义（忽略顺序和上下文）；Word2Vec 学出低维稠密向量，并通过词的共现关系让语义相近的词在空间中靠近。
2. CBOW 用多个周围词预测中心词，数据是（周围词列表， 中心词），隐藏层取周围词嵌入的平均；Skip-Gram 用中心词预测周围词，数据是（中心词， 周围词）成对的二元组。
3. 从 input_to_hidden 的权重矩阵取；线性层版用 `weight[:,idx]` 取列，嵌入层版用 `weight[idx]` 取行。
4. CrossEntropyLoss 内部已结合 LogSoftmax 和 NLLLoss，softmax 隐含其中；传索引是因为该损失函数只需正确类别的索引，无需处理高维稀疏向量，效率更高。
5. 预测能力是训练的副产品，目的是让权重矩阵习得词的稠密向量表示；词向量可作为文本分类、相似度比较、命名实体识别等下游 NLP 任务的输入特征。

词有了坐标，下一步是让句子的顺序产生意义——这正是第3章的神经概率语言模型和循环神经网络要解决的问题。
