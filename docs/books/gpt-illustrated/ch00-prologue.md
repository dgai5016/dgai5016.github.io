## 二、核心概念通俗解读

### NLP 三阶段：规则 → 统计 → 深度学习

- **起点**：20 世纪 50 年代图灵提出图灵测试——程序在对话中表现得像人就算有智能，AI 最早的愿景就和 NLP 绑在一起。
- **基于规则**：此后几十年用语法语义规则硬写，但规则太多太复杂，涵盖不了所有语言现象，此路不通。
- **基于统计**：1970 年后，IBM 贾里尼克团队用统计方法做语音识别，把规则问题变成了数学问题，准确率质的飞跃。语言模型（Language Model, LM）就此定义：捕捉词汇、短语、句子概率分布的统计模型——说白了，给每句话打一个「像不像人话」的分。
- **深度学习+大数据**：算力上来后，深度神经网络吃下海量文本成为主流，预训练模型在不少任务上已超过人类。

序章还带过神经网络「两落三起」（感知器、反向传播、AlexNet……），混脸熟即可。

### 语言模型进化时间线：六个刻度

| 年份 | 技术 | 一句话概括 |
|---|---|---|
| 1948 | N-Gram | 看前 N-1 个词，猜第 N 个词 |
| 1954 | 词袋 BoW | 文本是单词集合，不管顺序，只记词频 |
| 1986 | 分布式表示 | 词变成向量，语义分散在各维度，解决词袋的「词汇鸿沟」 |
| 2003 | NPLM | 用神经网络学词间关系，CNN/RNN/LSTM 的起点 |
| 2013 | Word2Vec | 训练神经网络学词向量；CBOW 用上下文猜中心词，Skip-Gram 反过来 |
| 2018 后 | Transformer 预训练 | 更大语料+更复杂架构，预训练+微调一统江湖 |

图上半是语言模型、下半是词向量两条线，后者为前者提供更高质量输入。

### 两种使用范式：微调 vs 提示/指令

预训练（白话：先让模型在海量无标注文本上「通读天下」）产出基础模型，学到词汇、语法、句子结构等通用知识。用法有二。**预训练+微调**：在较小的有标注数据集上做有监督学习，调整模型头部或部分参数，适配具体任务，比从头训练快得多、省数据得多。**提示（Prompt）/指令（Instruct）**：GPT 类生成式模型崛起后，不动参数，直接在输入里给出恰当的信息和指导，引导模型产出有用的输出。书里说：大模型本身就是知识库，不一定非得微调，但你得知道怎么把知识「调」出来。不好的输入很大程度上意味着不好的输出，提示工程应运而生。

换个说法：预训练像招进博览群书的通才；微调是岗前培训（改的是人），提示是把需求讲清楚（改的是你说的话）。

### BERT 填空 vs GPT 接龙

同为预训练模型，训练像两种习题：BERT 做填空题——随机遮词，靠上下文（双向）猜被遮的词，练理解；GPT 做文字接龙——看上文（单向）预测下一个词，练生成。书里判断：GPT 更接近语言模型的本质——实际要的是「接着往下写」，而「预测下一个词」紧凑有效地再现了这一生成过程。

初代 GPT 1.17 亿参数 → GPT-2 15 亿 → GPT-3 1750 亿，指数级增长；ChatGPT 基于 GPT-3.5，重点在聊天微调、提示工程、可控性与安全。参数和语料涨到一定程度，模型自然长出没人显式编程的新能力——「涌现能力」。

## 四、易错点/误区

**预训练 vs 微调的分工**：

| | 预训练 | 微调 |
|---|---|---|
| 数据 | 海量无标注文本 | 较小的有标注数据集 |
| 干什么 | 学通用语言知识，产出基础模型 | 调整头部或部分参数，适配具体任务 |
| 成本 | 极高——训练一次可达几百万美元 | 低得多、快得多 |

最常见的错：把微调当「重新训练」——它只是调整头部或部分参数，不是从零再来。

**Prompt vs Instruct**：

| | Prompt 模式 | Instruct 模式 |
|---|---|---|
| 输入 | 一个词或短语 | 一条明确指令 |
| 适合 | 生成式任务（文本生成、摘要） | 需要明确指示的任务（问答、解释概念） |
| 书中例子 | 输入「从前」→「有个山，山里有个庙……」 | 输入「请给我讲个故事」→ 返回完整故事 |

再纠一个误会：提示/指令与「预训练+微调」不是谁淘汰谁——都依赖预训练的迁移学习，区别只在：一个改参数，一个改输入。

## 五、复习自测

先自己答，再看参考答案。

1. NLP 从「基于规则」转向「基于统计」的转折点是什么？基于规则的方法为什么行不通？
2. BERT 和 GPT 的预训练分别像做什么题？为什么书里说 GPT 更接近语言模型的本质？
3. Prompt 模式和 Instruct 模式的区别是什么？各举一例。
4. 预训练和微调各用什么数据、各解决什么问题？

**参考答案**

1. 1970 年后，IBM 贾里尼克团队用统计方法做语音识别，把规则问题变成数学问题；规则方法涵盖不了所有语言现象。
2. BERT 做填空题：随机遮词，双向猜被遮的词；GPT 做文字接龙：看上文（单向）预测下一个词。实际要的是「接着往下写」，所以 GPT 更接近语言模型的本质。
3. Prompt 输入词或短语（如「从前」），适合生成式任务；Instruct 输入明确指令（如「请给我讲个故事」），适合需明确指示的任务。
4. 预训练用海量无标注文本，学通用语言知识、产出基础模型；微调用小规模有标注数据调参数适配任务，更快更省数据。
