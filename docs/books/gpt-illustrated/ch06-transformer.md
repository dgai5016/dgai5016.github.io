第5章里，注意力已从「RNN 的外挂」长成独立部件，但主干仍是循环网络。本章是全书最长的架构章：把循环结构整个拆掉，总装出 GPT 的承重墙——Transformer。

## 一、本章解决什么问题：把循环结构请下牌桌

2017 年，谷歌大脑的瓦斯瓦尼等人在论文《Attention is All You Need》（你只需要注意力）中提出 Transformer。原书点明时代背景：当时 NLP 主流是 RNN 和 LSTM，但计算效率低、难捕捉长距离依赖，还有梯度消失和梯度爆炸的老毛病。

第5章的注意力终究只是给 RNN 打工的配件，而这篇论文的标题就是宣言——咖哥原话：「今后不再需要任何循环神经网络结构来处理 Seq2Seq 类型的问题了」，这在 LSTM 如日中天的年代是一颗重磅炸弹。扔掉循环换来两大好处：一是序列所有位置并行处理（RNN 必须一个词一个词往后传），训练大幅提速；二是自注意力让任意两个位置直接建立联系，长距离依赖不再靠一步步传递。

## 二、核心概念通俗解读

### 编码器-解码器分工：框架没变，内核全换

Transformer 仍是 Seq2Seq 的编码器-解码器框架：编码器把输入序列转换为一种表示，解码器根据这种表示生成输出序列。变的是内部——所有循环结构被自注意力取代。

### 自注意力四步

复习第5章：①每个元素投影成 Q、K、V 三个向量；②Q 与 K 点积，除以缩放因子（K 维度的平方根）得到注意力分数；③softmax 归一化成权重；④权重加权 V 求和得输出。关键差别在于：引入自注意力后，编码器和解码器可以同时处理序列中的所有元素、让它们互相作用，而不是一个接一个——这正是并行提速的来源。

### 多头自注意力：一支评审团

换个说法，多头就像请了多位评委各看一个角度再汇总意见——原书的类比是「一个小团队，每个成员都在关注输入序列的不同方面」（灵感来自多任务学习）。每个头用自己的权重参数独立算注意力，各头输出拼接后再过一层线性变换整合。书中实现取嵌入维度 512、8 个头、每头 64 维（512 = 8 × 64，正好整除）。多头既用于两个自注意力子层，也用于编码器-解码器注意力。

### 三种注意力各在哪

Transformer 里有三种注意力：编码器自注意力、解码器自注意力、编码器-解码器注意力。前两种是序列自己打量自己；第三种是解码器去「查」编码器——Q 来自解码器上一层的输出，K 和 V 来自编码器的输出。各自配什么掩码最容易混，第四段给对比表。

### 位置编码：给每个座位贴门牌号

Transformer 并行处理、不按位置顺序读序列，天生「不知道词的先后」，所以必须把位置信息叠加上去。换个说法，位置编码像给剧场每个座位贴门牌号：词向量说明你是谁，位置编码说明你坐第几排。原论文用正弦位置编码：

`PE(pos, 2i) = sin(pos / 10000^(2i/d))`（偶数维）

`PE(pos, 2i+1) = cos(pos / 10000^(2i/d))`（奇数维）

逐个符号看：pos 是词在句中的位置，取 0 到 seq_len−1；d 是词向量维度（书中代码取 512）；i 是维度对的下标，从 0 到 d/2−1；10000 是固定基数；偶数维取 sin、奇数维取 cos。

拿 pos=1、d=512 代入走一遍：第 0 维（i=0）分母是 10000^0 = 1，PE = sin(1/1) ≈ 0.841；第 1 维 PE = cos(1) ≈ 0.540；第 2 维（i=1）分母 10000^(2/512) ≈ 1.037，PE = sin(0.965) ≈ 0.822；而轮到很靠后的维度（2i 接近 d），分母趋近 10000，角度被压到约 0.0001，正弦值几乎不动。规律：靠前的维度随位置变化快（细刻度），靠后的维度变化慢（粗刻度），一套编码同时携带多尺度的位置信息。

小冰问过一个人人都想问的问题：直接用 1、2、3、4 编号不行吗？咖哥答：自然数编码是线性的，相邻位置的差恒定；正弦余弦有周期性和正交性，在各个尺度上都有区分性，捕捉更复杂的位置关系（尤其长距离）更有优势。书中也提到把位置编码当参数学的可学习位置编码。

### Add & Norm：残差连接与层归一化

每个子层的输出都走同一道后处理：与输入相加（残差连接），再做层归一化，合称 Add & Norm。白话说：残差连接是给信息修一条跨层直达通道，输入直接连到输出和后续层，信息传递更高效，还能缓解梯度消失和梯度爆炸；层归一化把每层输入的数值分布拉平稳（书中说是缓解「内部协变量偏移」，即层与层之间输入分布的变化），让训练更稳、收敛更快、能用更大的学习率。代码就一行：`output = self.layer_norm(output + residual)`。

### 前馈网络：逐位置加工

注意力之后再接逐位置前馈网络：升维（512→2048）、过 ReLU、再降回 512，同样带残差和层归一化。「逐位置」（Position-wise）指对每个 token 独立做同样的变换，不把序列摊平、不受其他位置影响。书里用 kernel_size=1 的一维卷积代替论文中的全连接层——卷积在各位置共享权重，参数更少。咖哥点题：多头注意力和前馈网络都严格保持「队形」，不打乱、不整合、不循环，这种对位置信息的完整保持加并行处理，正是 Transformer 的核心思路。

### 右移一位与后续掩码

解码器的输入有个别扭的名字：Output——因为它既是解码器现在的输入，又是之前的输出。训练时用教师强制，把目标序列真值右移一位、开头补 `<sos>`：

`['咖哥 喜欢 小冰', '<sos> KaGe likes XiaoBing', 'KaGe likes XiaoBing <eos>']`（源句 / 解码器输入 / 目标）

生成式任务同理：源序列 `<sos> 今天天气真好，我们去`，目标 `今天天气真好，我们去 <eos>`。

既然各位置并行计算，为什么还要右移？为了配合后续掩码：在「今」的位置只许看 `<sos>`，在「天」的位置只许看 `<sos>` 和「今」，依此类推。右移加掩码，等于在并行计算里模拟出「从左到右逐词生成」——既不偷看未来，又不用真的串行。带后续掩码的注意力也叫因果注意力。掩码的实现就是一张上三角矩阵：`np.triu(np.ones(...), k=1)`，对角线及以下为 0（可看），以上为 1（不可看）。

### 输出头：一个躯干接五种任务

解码器最后的特征向量先过线性层映射到词汇表大小，再 softmax 成每个位置的概率分布。之后按下游任务换头：机器翻译和文本摘要直接用词汇表分布配交叉熵（解码可用贪心或集束搜索）；文本分类换成输出类别分布的全连接层；问答用两个全连接层分别预测答案的起始和结束位置；命名实体识别则给每个位置输出标签分布，用逐位置交叉熵。

## 三、书中实验讲解

原书按「从中心到两边、从左到右」的顺序逐一实现十大组件：缩放点积注意力、多头自注意力（含残差和层归一化）、逐位置前馈网络、正弦位置编码表、填充掩码函数、编码器层、编码器、后续掩码函数、解码器层、解码器，最后组装成 Transformer 类加线性投影层。要点：

- 掩码生效只靠一行：`scores.masked_fill_(attn_mask, -1e9)`——被遮位置的分数直接改成极小值，softmax 后权重趋近 0
- 解码器把填充掩码与后续掩码相加，再用 `torch.gt(..., 0)` 合成一张布尔掩码；解码器-编码器注意力只用填充掩码
- 编码器和解码器都由 6 层堆叠而成——章名「层峦叠翠上青天」说的就是层层相叠、功力倍增

训练用的还是那 5 组中英例句（这次封装进 TranslationCorpus 类，自动建词典、出批次），交叉熵损失加 Adam（学习率 0.0001）。100 轮下来损失从第 20 轮的 0.0197 一路降到 0.000925。

测试却翻了车：一次前向传播直接输出整句，结果是 `['KaGe', 'KaGe', 'KaGe', 'KaGe', 'KaGe']`——只翻对第一个词就原地复读。面对小冰「还不如 RNN 版 Seq2Seq」的抱怨，咖哥先搬出奥卡姆剃刀，但随即点破：这次翻车的真正原因与模型复杂度无关，而是没有用自回归机制逐位置生成——推理时应把解码器每一步的输出接回输入当下一步的输入，每步选概率最大的词（贪心搜索）或用集束搜索，逐步生成。怎么接，下一章用 GPT 演示。

## 四、易错点/误区

三种注意力必背的对比表（按原书表格整理，补上 Q/K/V 来源）：

| 注意力机制 | Q 来自 | K、V 来自 | 填充掩码 | 后续掩码 |
|---|---|---|---|---|
| 编码器自注意力 | 编码器输入 | 编码器输入 | 是 | 否 |
| 解码器自注意力 | 解码器输入 | 解码器输入 | 是 | 是 |
| 编码器-解码器注意力 | 解码器上一层输出 | 编码器输出 | 是 | 否 |

再纠四个易混点：

1. **位置编码为什么必须加**：不是锦上添花。并行结构不按位置顺序处理序列，模型无法自己学到位置信息，不加编码就分不清「不同位置的词」。
2. **后续掩码为什么只在解码器**：编码器读的是完整输入句，看全句天经地义；解码器是生成方，生成第 n 个词时「未来」尚不存在，偷看等于抄答案。编码器-解码器注意力面对的是整个源序列，同样不需要后续掩码——原书思考题专门考了这一点。
3. **解码器的输入和输出都叫 Output**：训练时它是右移一位的真值，推理时它是模型已生成的词，别被名字绕晕。
4. **奥卡姆剃刀的正确用法**：它说的是解释现象应选假设最少、最简单的模型，简单数据集上优先简单模型；但本章测试翻车的锅不在复杂度，而在没做自回归——先找用法问题，再怀疑架构。

## 五、复习自测

先自己答，再看参考答案。

1. Transformer 里有几种注意力？各装在哪个组件、配什么掩码？
2. 位置编码为什么必须有？正弦编码比直接用 1、2、3、4 好在哪？
3. 逐位置前馈网络的「逐位置」是什么意思？书中为什么用 kernel_size=1 的一维卷积代替全连接层？
4. 解码器输入为什么也叫 Output？训练时为什么要右移一位？
5. 测试时为什么只翻出首词就开始复读？怎样才能翻对？

**参考答案**

1. 三种：编码器自注意力（填充掩码）、解码器自注意力（填充+后续掩码）、编码器-解码器注意力（Q 来自解码器、K/V 来自编码器输出，仅填充掩码）。
2. 并行结构不按顺序处理序列，位置信息天生缺失；正弦余弦有周期性和正交性，各尺度都有区分性，比线性的自然数更能捕捉复杂（尤其长距离）位置关系。
3. 对每个 token 独立做同样的升维-激活-降维变换，不打乱不整合序列；一维卷积在各位置共享权重，比不共享权重的全连接层参数更少。
4. 训练时教师强制喂的是目标序列真值右移一位（开头补 `<sos>`），它是「上一时刻的输出」；右移配合后续掩码，让每个位置只能根据前文预测下一个词，并行计算中模拟出自左向右的生成。
5. 一次前向直接输出整句，没有把每步预测接回输入逐步生成；应采用自回归解码——每步选概率最大的词（贪心搜索）或用集束搜索，逐词生成。

拆掉了循环、总装了十大组件，Transformer 已经立起来；留下的悬念是「怎么让它好好说话」——第7章的自回归生成正好接上这块拼图。
