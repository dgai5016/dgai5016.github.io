第4章的 Seq2Seq 已经能翻译，但留了个心病：整句话被压进一个向量。本章的注意力机制（Attention）就是药方。这篇解读按「问题 → 概念 → 实验 → 误区 → 自测」五段走。

## 一、本章解决什么问题：一张便签装不下整句话

Seq2Seq 的老方案：编码器读完整句话，把全部信息压进一个固定长度的上下文向量，解码器翻译时手里只有这张「便签」。句子一长，便签写不下，信息就被挤掉了。原书说得很直白：如果编码器无法动态捕捉每个单词的上下文信息，就无法正确地对与上下文相关的单词编码——这也是 NPLM、RNN 时代共同的老毛病。

注意力的解法：别再逼模型把整句压进一个向量。解码器每生成一个词，都允许它「回看」原句的每个位置，按相关程度分配权重——重要的多看几眼，不重要的扫一眼就过。打个比方：口译员不再只靠一张便签，而是给原句每个词单独记一张卡片，译到哪儿就翻一遍卡片，重点卡片反复看。

## 二、核心概念通俗解读

### 点积注意力：打分、归一、取货

先看原书的类比：推荐系统里，用户兴趣向量 U 和电影特征向量 M 做点积，分越高代表用户越喜欢这部电影——点积就是「匹配度打分器」，方向越一致分越大，正交则为零。

点积注意力把这个打分器用在两个序列 x1 和 x2 之间，四步走：① x1 与 x2 的每个位置两两点积，得到相似度得分（书中称「原始权重」）；② softmax 归一化成注意力权重；③ 用权重对 x2 加权求和得到输出。手算一遍点积：四维向量 [1,0,1,0] 与 [0,2,0,2] 点积为 0（正交，不相关），与 [2,1,2,1] 点积为 4（同向，高度相关）——分数就是相关度。

softmax 那一步，白话是把得分变成「百分比」。拿 [2,1,0] 手算：指数化得 e²≈7.39、e¹≈2.72、e⁰=1，总和≈11.11，相除得 [0.67, 0.24, 0.09]——每个值在 0~1 之间，加起来正好是 1。「注意力权重」就是每个位置该被看的百分比。

最后按百分比把 x2 的向量混合取回。关键理解（书里反复强调）：输出和 x1 形状完全相同，是「关注了 x2 之后的新 x1」——每个词的表示从此整合了全序列上下文，词嵌入的内涵被显著延展。

### 缩放点积注意力：给打分器降降温

类比：会议上一个人嗓门特别大，全场就只剩他的声音。softmax 对大数值很敏感——特征维度一大点积就很大，softmax 把几乎全部权重砸给最高分，落进陡峭的饱和区，梯度变得极小，训练「学不动」了（梯度消失）。办法很简单：softmax 之前把得分除以 √d（d 是特征维度），相当于整体调低音量——差距还在，但不至于一言堂。公式即 `Attention(Q,K,V)=softmax(QKᵀ/√d)V`。

数字代入：特征维度 d=4，缩放因子 √4=2。得分 [2,1,0] 不缩放时 softmax 是 [0.67, 0.24, 0.09]；除以 2 变成 [1, 0.5, 0] 后，softmax 是 [0.51, 0.31, 0.19]——最高分的优势被削弱，分布更平缓。代码上就一行：`scaling_factor = x1.size(-1) ** 0.5`。

### 编码器-解码器注意力：把打分器装进翻译机

现在给 x1、x2 赋予身份：x1 是解码器各时间步的隐藏状态，x2 是编码器的。注意方向——是解码器去「查」编码器，所以也有人叫它「解码器-编码器注意力」。

解码器每走一步，都用当前状态对编码器的全部状态打分、归一、加权取货，得到一个上下文向量 context，相当于「此刻最该回看的原句信息」。解码器把它和自己 RNN 的输出拼接在一起（所以输出线性层的输入维度翻倍成 2×hidden_size），再预测下一个词。

### Q、K、V：图书馆检索三件套

前面一直说 x1、x2，而 Transformer 文献里满篇 Q、K、V。类比图书馆检索：Q（Query，查询）是你输入的检索词——「我想找什么」；K（Key，键）是每本书书脊上的标签——用来和检索词比对；V（Value，值）是书里的实际内容——比对完按相关度取用的货。流程：Q 和 K 算相似度，归一化成权重，权重作用在 V 上加权求和。

最简示例里 Q=x1、K=V=x2；Transformer 里三者由同一输入序列经三次不同的线性变换得到。维度规则（咖哥特意强调）：K 的特征维度必须与 Q 相同（否则没法点积）；K 和 V 的序列长度要一致（描述同一个序列）；V 的特征维度决定输出的特征维度。

### 自注意力：序列自己打量自己

术语白话翻译：「自注意力」就是一个序列自己打量自己——把 x2 换成 x1 本身，每个位置都对其他所有位置（含自己）打分取货。比如「自然 语言 处理」里的「处理」，经过自注意力后不再只代表「处理」这个词，而是融合了「自然」「语言」的信息——词表示从「代表自己」升级为「自己 + 全序列上下文」。

带 Q、K、V 的版本也不神秘：用三个 Linear 层把 x 分别变换成 Q、K、V，再做缩放点积注意力即可。

### 多头自注意力：多位评委同时打分

类比：作文比赛请多位评委——有人专看结构，有人专看文笔，有人专看立意，各打各的分，最后合议。多头自注意力就是对 Q、K、V 做多组不同的线性变换，得到多个「头」，每个头在自己的子空间里独立做缩放点积注意力，再把各头结果拼接起来，过一次线性变换输出。

书中代码取 num_heads=2、head_dim=2，feature_dim=4——注意 feature_dim 必须能被头数整除（4=2×2），否则切不出等份的子空间。好处：多个子空间并行捕捉不同特征，长距离依赖和不同语义层次都能照顾到。

### 注意力掩码：两块遮布

先排个雷：这里的掩码不是 BERT 完形填空那种挡词操作。注意力掩码的作用是：算注意力时别把不相干的位置算进来。实现：把掩码矩阵加到得分上，让不该看的位置变成接近负无穷，softmax 后权重趋近 0，等于被遮住。

- **填充掩码（Padding Mask）**：批量训练时句子长短不齐，要用 `<pad>` 补齐，这些填充位毫无意义还会引入噪声，得遮住。书里类比损失函数的 `ignore_index`——同样是告诉模型「这些位置别理」。
- **后续掩码（Subsequent Mask，也叫前瞻掩码）**：解码器专用，遮住当前位置之后的「未来信息」。类比考试时把后面的题目遮住，不许偷看答案——生成第 n 个词时只能看前 n 个词。细节留到下一章。

### 注意力家族一瞥

书上还报了一串名字，混个脸熟即可：加性注意力（Bahdanau，用带 tanh 的全连接层算相似度）、全局与局部注意力（看全句 vs 只看一个窗口）、自适应注意力、分层注意力（先看词级再看句级）、因果注意力（后续掩码的正式名称），可按任务组合选用。

## 三、书中实验讲解

本章实验分两级：先拿随机张量做「玩具实验」拆机制，再把它装进 Seq2Seq 做真翻译。

**玩具实验**：x1 形状 (2,3,4)、x2 形状 (2,5,4)（批次、序列长、特征维）。全部注意力由三次矩阵运算完成：`torch.bmm(x1, x2.transpose(1,2))` 算出 3×5 的相似度得分；`softmax(dim=2)` 后每一行加起来是 1；再 `torch.bmm(attn_weights, x2)` 加权取货，输出形状 (2,3,4)，和 x1 完全同形。这个实验说明注意力没有任何黑魔法——就是「打分 + 归一 + 加权求和」，输出是「关注了 x2 之后的新 x1」。

**Seq2Seq + 注意力翻译实验**：语料还是那 5 句中英对照，改造三处：新增 Attention 类（核心三行：matmul 算分、softmax 归一、matmul 加权）；解码器把 context 与 RNN 输出拼接进输出层；Seq2Seq 把编码器的 output 传给解码器——第4章「编码器 output 留给注意力用」的伏笔在此兑现。训练 400 轮，损失从 0.053 一路降到 0.006；测试两句全部翻对。最有说服力的是注意力热力图：模型译「NLP」时对源句「自然」的权重几乎是 1——没人教过对齐，模型自己学会了「译哪个词就盯哪个词」。书里也提醒：语料只有 5 句，学到的模式偏简单，大规模语料才能训出丰富的注意力分布。

## 四、易错点/误区

**得分 vs 权重**，书里专门花段落区分：

| | 注意力得分（原始权重） | 注意力权重 |
|---|---|---|
| 怎么来的 | 点积直接算出，未经处理 | 得分（缩放、加掩码）后过 softmax |
| 数值范围 | 任意实数 | 0~1，每行和为 1 |
| 角色 | 中间半成品 | 真正用来加权取货的系数 |

**两种掩码**：

| | 填充掩码 | 后续掩码 |
|---|---|---|
| 遮什么 | `<pad>` 填充位 | 当前位置之后的未来 token |
| 为什么 | 填充无意义、引噪声 | 生成时不能偷看答案 |
| 用在哪 | 编码器、解码器都用 | 只在解码器 |

**Q/K/V 谁来自谁**，最容易背串：

| 场景 | Q 来自 | K、V 来自 |
|---|---|---|
| 编码器-解码器注意力 | 解码器隐藏状态 | 编码器隐藏状态（K=V） |
| 自注意力 | 同一序列的一次线性变换 | 同一序列的另两次线性变换 |

再纠三个常见误会：① 两次 `bmm` 是同一个函数，第一次叫点积（算相似度），第二次叫加权和（聚合信息），角色不同；② 缩放因子不是为了让结果更准，而是防止 softmax 进饱和区导致梯度消失，保的是训练稳定；③ 注意力掩码和 BERT 的完形填空掩码只是重名，机制完全不同。

## 五、复习自测

先自己答，再看参考答案。

1. 点积注意力的四步是什么？两次 bmm 分别在算什么？
2. 缩放点积注意力为什么要除以 √d？不除会发生什么？
3. 在编码器-解码器注意力中，Q、K、V 分别来自谁？
4. 填充掩码和后续掩码各遮住什么？实现上怎么「遮」？
5. 多头自注意力的「多头」是怎么多出来的？为什么 feature_dim 要能被头数整除？

**参考答案**

1. 创建 x1/x2 → 点积得相似度得分 → softmax 归一化成注意力权重 → 对 x2 加权求和。第一次 bmm 是 x1 与转置后的 x2 相乘算相似度；第二次是权重与 x2 相乘，取回加权信息。
2. 特征维度大时点积值偏大，softmax 落入陡峭的饱和区，梯度极小甚至梯度消失；除以 √d 让 softmax 工作在平缓区，训练更稳定。
3. Q 来自解码器隐藏状态，K 和 V 都来自编码器隐藏状态（简版实现里 K=V，同一输出兼任两角色）。
4. 填充掩码遮 `<pad>` 填充位，后续掩码遮当前位置之后的未来信息；都是把不该看的位置的得分加上接近负无穷的数，softmax 后权重趋近 0。
5. 对 Q、K、V 做多组不同的线性变换，每组一个头，各自做缩放点积注意力后拼接、再线性变换；因为 feature_dim 要按头数均分为 num_heads × head_dim，不能整除就切不出等份子空间。

走完这一章，注意力已从「RNN 的外挂」变成独立完整的部件；再往前一步，就是第6章的 Transformer——它将成为整栋建筑的承重墙。
