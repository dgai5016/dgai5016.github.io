## 前言

**本章解决什么问题**：开场先立起全书的坐标系——NLP 技术如何从数词频的统计方法一步步演进到 GPT-4，让后面每一章的技术都能在这条传承链上找到自己的位置。

### 核心概念
- **技术传承链**：整本书的主线，即 N-Gram/Bag-of-Words → Word2Vec → NPLM → RNN → Seq2Seq → Attention → Transformer → BERT/GPT → ChatGPT → GPT-4，每个环节都在弥补上一环的短板。
- **统计启蒙期（N-Gram、Bag-of-Words）**：最早的文本处理方法，只关注词频和局部词序，还谈不上「理解」语义。
- **语义萌芽（Word2Vec）**：第一次从词频和局部序列中捕捉到词汇的语义信息，实现了词嵌入的突破。
- **神经语言模型（NPLM、RNN）**：神经网络开始接管词序列建模，RNN 进一步增强了长距离依赖的捕捉能力。
- **序列转换（Seq2Seq、Attention）**：编码器-解码器架构把输入序列映射到输出序列，注意力机制让生成时能「盯着」输入的关键部分，二者是 Transformer 的直接前身。
- **架构革命（Transformer）**：彻底抛弃 RNN，全面转向自注意力，换来高效并行计算，成为后世所有大模型的底座。
- **预训练双雄（BERT、初代 GPT）**：同样基于 Transformer，BERT 走双向理解路线，GPT 走单向生成路线。
- **对话与通用智能（ChatGPT、GPT-4）**：靠任务设计、微调策略尤其是基于人类反馈的强化学习获得对话能力；GPT-4 以空前的参数与数据规模展现出跨领域通用智能，被誉为「通用人工智能的星星之火」。

## 序章

**本章解决什么问题**：回答「GPT 是从哪儿来的」——从 NLP 的规则与统计之争讲起，确立预训练范式，摆开 BERT 与 GPT 两条路线之争，为全书铺垫历史与范式背景。

### 核心概念
- **图灵测试与 NLP 起源**：NLP 的问题意识可追溯到图灵测试——机器若能在对话中表现得像人，即可视为有智能，可见 NLP 是 AI 与生俱来的核心命题。
- **基于规则的困境**：早期靠人工编写语法语义规则处理语言，规则数量庞大且无法覆盖所有语言现象，这条路最终走不通。
- **基于统计的语言模型（Language Model, LM）**：把 NLP 从「写规则」变成「解数学」，用统计模型捕捉词汇、短语、句子的概率分布，估计一段文本序列出现的概率，这是全书一切语言模型的定义原点。
- **深度学习与大数据驱动**：统计路线确立后，算力提升与深度神经网络结合，用海量数据学习语言的复杂结构与语义，成为当今主流。
- **预训练与基础模型（Foundation Model）**：在大量无标注文本上训练大模型，让其学到词汇、语法、句法与上下文知识，所得模型也叫基础模型，是下游任务的通用底座。
- **「预训练 + 微调」范式**：预训练学到的语言知识很容易迁移到下游任务，只需在小规模标注数据上微调模型头部或部分参数，比从头训练更快、更省数据。
- **Prompt / Instruct 模式与提示工程**：不微调，直接通过输入引导大模型输出——Prompt 给词或短语引导生成（如输入「从前」），Instruct 给明确指令要求完成任务（如「请讲个故事」）；设计好输入的技能即提示工程（Prompt Engineering），输入质量很大程度决定输出质量。
- **BERT 填空 vs GPT 接龙**：BERT 的预训练像做填空题，随机遮词、靠双向上下文猜词，重理解；GPT 像文字接龙，从左到右预测下一个词，重生成。语言模型的核心任务本就是根据上下文生成合理后续，GPT 更贴近这一本质，因此后来居上。
- **涌现能力（Emergent Capabilities）**：随着参数从初代 GPT 的 1.17 亿、GPT-2 的 15 亿涨到 GPT-3 的 1750 亿，模型自然展现出未被显式编程的新能力，这一现象是 ChatGPT 能力的来源之一。

## 第1章 高楼万丈平地起：语言模型的雏形N-Gram和简单文本表示Bag-of-Words

**本章解决什么问题**：大模型的第一块地基——在神经网络登场之前，纯统计方法如何定义并初步解决「语言建模」问题：N-Gram 负责预测下一个词，Bag-of-Words 负责把文本变成可统计的向量，同时二者暴露的表示瓶颈直接引出下一章的词向量。

### 核心概念
- **语言模型**：一个估计文本概率分布的数学模型——判断一段文本序列在自然语言中出现的可能性，进而根据上文预测下一个最可能出现的词。
- **N-Gram 模型**：最早的统计语言模型，核心假设是「一个词的出现只依赖它前面的 N-1 个词」，用有限的局部上下文近似整句的联合概率；N=1/2/3 分别叫 Unigram、Bigram、Trigram。
- **条件概率估计**：$P(w_i \mid w_{i-1}) = \frac{count(w_{i-1}, w_i)}{count(w_{i-1})}$
  - 符号速查：$w_i$ 是当前词，$w_{i-1}$ 是紧邻的前一个词，$count(\cdot)$ 表示该片段在语料库中出现的次数；比值即「前一个词出现的前提下，下一个是它的概率」。
- **整句概率的链式近似**：$P(w_1, \dots, w_n) \approx \prod_{i=1}^{n} P(w_i \mid w_{i-1})$
  - 符号速查：$w_1, \dots, w_n$ 是句中的 $n$ 个词；把各步条件概率连乘即得整句概率，这是 Bigram 版本，N 更大时条件部分换成前 N-1 个词。
- **Gram、Token 与分词**：N-Gram 里的「元素」不一定是词，可以是字、子词（Subword）或短语；语料被切成可供模型读取的元素后，每个元素就是一个 Token，分词是 NLP 的关键预处理环节（英文常用 NLTK、spaCy，中文常用 jieba，BERT 则用专属 Tokenizer）。
- **子词分词算法**：把词切成更小的子词来处理未登录词、拼写错误和词汇变化，减小词汇表、提升泛化；代表算法 WordPiece（如 "playing" 切为 play + ##ing）和 SentencePiece，能从数据中自动学出高频子词。
- **Bag-of-Words（词袋模型）**：把文本看作一袋子无序的词，只统计每个词出现的次数，将句子表示为词频向量；丢掉词序信息，反而在文本分类、情感分析等任务中简单好用。
- **One-Hot 编码**：词袋表示的特例——单词独立成句时，词袋向量退化为只在对应索引处置 1、其余全 0 的向量。
- **余弦相似度**：$sim(A, B) = \frac{A \cdot B}{\|A\| \, \|B\|}$
  - 符号速查：$A$、$B$ 是两个文本向量，分子是点积，$\|A\|$、$\|B\|$ 是向量范数（长度）；取值 -1 到 1，越接近 1 越相似。它只看向量夹角不看长度，能抵消句子长短差异，适合文本这类高维数据；欧氏距离则关注实际距离，适合聚类、推荐等场景。
- **两种方法的局限**：N-Gram 只看前 N-1 个词，无法捕捉远距离依赖，且 N 增大会导致数据稀疏；词袋是高维稀疏向量、忽略上下文，词在向量空间中的相对位置没有语义。破局方向：低维稠密向量 + 上下文关系，即下一章的词向量。

## 第2章 文君文本何所似：词的向量表示Word2Vec和Embedding

**本章解决什么问题**：接住第1章留下的「高维稀疏、无语义」表示瓶颈——用神经网络从上下文中学出低维稠密的词向量，让「语义相近 = 向量相近」从一个愿望变成可训练的目标，也为后续所有神经语言模型准备好输入格式。

### 核心概念
- **词向量与词嵌入（Word Embedding）**：把词映射到固定维度的连续向量空间，用各维度数值的相似程度衡量词与词的语义远近；日常两者可互换，细分时「词向量」指具体的向量结果，「词嵌入」偏指映射的过程与方法（含训练算法）。
- **分布式表示（Distributed Representation）**：思想源自 1986 年反向传播论文——词的语义分散存放在向量的各个维度上（如某些维度渐渐蕴含性别、年龄信息），从而捕捉词与词的相似性和关联性，弥补 One-Hot 与词袋的「词汇鸿沟」。
- **Word2Vec 的核心思想**：「近朱者赤」——一个词的含义由它周围的词决定，训练时把词和它的上下文一起学习，语义相近的词自然在向量空间靠近。
- **稀疏向量 vs 稠密向量**：词袋和 One-Hot 是高维稀疏（大量维度为 0）；Word2Vec 输出低维稠密向量（几维到几百维），信息密度高、含语义句法关系。
- **CBOW（连续词袋）**：用周围的上下文词预测中心词；多个周围词的嵌入向量取平均值作为隐藏层输出，训练数据形如（周围词列表，中心词）。
- **Skip-Gram（跳字）**：与 CBOW 方向相反，用中心词预测周围的上下文词；一个中心词配多个周围词，形成多组（中心词，周围词）训练对。
- **预测是手段，嵌入才是目的**：两个模型本质是只有输入层-隐藏层-输出层的浅层网络，真正要的是输入层到隐藏层的权重矩阵（用 nn.Linear 时每一列、用 nn.Embedding 时每一行就是一个词的词向量）；预测词的任务只是驱动权重学习的幌子。
- **softmax 函数**：$\text{softmax}(x_i) = \frac{e^{x_i}}{\sum_{j=1}^{n} e^{x_j}}$
  - 符号速查：$x_i$ 是模型输出向量（得分）的第 $i$ 个元素，$n$ 是向量维度（等于词汇表大小）；分母归一化后各元素落在 0 到 1 且总和为 1，可解释为每个词被预测的概率，并会放大得分差异使分布更尖锐。
- **CrossEntropyLoss 的隐含设计**：PyTorch 的交叉熵损失内部已结合 LogSoftmax 和 NLLLoss，所以无需显式做 softmax；它接收类别索引（而非 One-Hot 向量）作为目标值以省计算。
- **nn.Embedding 嵌入层**：比「One-Hot + nn.Linear」更标准的实现——本质是一张查找表，直接把词索引映射为嵌入向量，免去 One-Hot 编码与矩阵乘法，代码更简洁、计算更高效；参数为 num_embeddings（词汇表大小）和 embedding_dim（向量维度），取词向量用 weight[idx]。
- **Word2Vec 的局限**：一是静态词向量——每个词只有一个固定向量，无法区分一词多义；二是无法处理训练时没见过的未知词。后续的 GloVe 和 fastText 沿同一思路改进；且它不是完善的语言模型（未对整句概率建模），真正对上下文建模要等 RNN/LSTM/Transformer。

## 第3章 山重水复疑无路：神经概率语言模型和循环神经网络

**本章解决什么问题**：承接上一章词向量「只看词本身、不看上下文」的局限（无法处理一词多义和未登录词），本章先用 NPLM 把神经网络引入语言模型、用上下文预测下一个词，再用 RNN/LSTM 突破固定上下文窗口的限制，为后面 Seq2Seq 和 Transformer 铺路。

### 核心概念
- **NPLM（神经概率语言模型）**：2003 年 Bengio 提出，和 N-Gram 一样用前 N-1 个词预测第 N 个词，但改用神经网络来学这个概率分布——从此深度学习登上 NLP 舞台。
- **查找表 C（词嵌入层）**：把词的索引（One-Hot）换成连续向量，相当于一张全词共享的「字典」，减少参数量、提升泛化能力。
- **固定上下文窗口的局限**：NPLM 的 `n_step`（窗口大小）直接决定第一个线性层的输入尺寸，窗口外的前文一概看不见，也处理不了变长序列——这是 RNN 要解决的核心痛点。
- **RNN 的循环机制**：把上一步的隐藏状态「喂」回下一步，让网络拥有记忆，从而捕捉长距离依赖。当前隐藏状态的计算为 $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$
  - 符号速查：$h_t$ 为当前时间步隐藏状态；$h_{t-1}$ 为上一步隐藏状态；$x_t$ 为当前时间步输入；$W_{hh}$、$W_{xh}$ 为隐藏层到隐藏层、输入到隐藏层的权重矩阵；$b_h$ 为偏置。
- **时间步权重共享**：所有时间步复用同一套 $W_{hh}$、$W_{xh}$、$W_{hy}$，因此输入序列变长不需要改网络结构——代码里 `n_step` 从模型结构中消失就是明证。
- **BPTT（Through Time 反向传播）**：把 RNN 沿时间维度展开后再做反向传播，梯度从输出层沿时间步一路传回输入层，本质是链式法则在时序数据上的推广。
- **梯度消失与梯度爆炸**：梯度在长时间步上反复连乘导致的训练不稳定，是朴素 RNN 学不好长依赖的病根，也是 LSTM/GRU 门控机制的动机。
- **LSTM 的三门一细胞**：输入门、遗忘门、输出门决定「记住什么、忘掉什么、输出什么」，细胞状态像一条传送带按比例更新：$c_t = f_t \odot c_{t-1} + i_t \odot g_t$，$h_t = o_t \odot \tanh(c_t)$
  - 符号速查：$f_t$ 为遗忘门（历史保留比例，0 为全忘）；$i_t$ 为输入门（新信息保留比例）；$g_t$ 为细胞候选状态；$c_t$ 为细胞状态；$o_t$ 为输出门；$h_t$ 为当前隐藏状态。
- **RNN 时代的落幕伏笔**：RNN 必须按时间步顺序计算、无法并行，超长序列仍会丢信息，可扩展性有限——这正是「Attention is All You Need」摒弃 RNN 的原因。

## 第4章 柳暗花明又一村：Seq2Seq编码器-解码器架构

**本章解决什么问题**：翻译、摘要、对话这类「读进一个序列、写出另一个序列」的任务，用单个 RNN 一体化编解码会信息损失，本章引入 Encoder-Decoder 分工的 Seq2Seq 架构来化解——它正是 Transformer 的基础架构，其「固定向量瓶颈」又直接引出下一章的注意力机制。

### 核心概念
- **Seq2Seq 架构**：2014 年 Sutskever 等人提出，把「序列到序列」的映射拆成两半——编码器压缩、解码器解压，可类比电报/电话系统中先把声音编码成电信号、再在另一端解码还原。
- **Encoder（编码器）**：用 RNN 逐词读入输入序列，每步更新隐藏状态，跑完后的隐藏状态就是「上下文向量」，可视为对整句输入的总结。
- **Decoder（解码器）**：拿编码器的隐藏状态作为自己的初始隐藏状态，逐个生成输出符号，并把上一步的生成结果当作下一步的输入——即自回归（Autoregressive）生成方式。
- **输入输出长度可解耦**：编码器输入和解码器输出的长度可以不同，所以天然适合机器翻译、问答、文本摘要这类生成型任务。
- **Teacher Forcing（教师强制）**：训练时把真实目标序列（而非模型自己生成的词）喂给解码器作输入，让模型在正确起点上学「下一个词」，收敛更快、训练更稳。
- **Exposure Bias 与 Scheduled Sampling**：教师强制的副作用——训练吃「标准答案」、测试只能吃自己生成的词，两边数据分布不匹配；缓解办法是训练时按一定概率改喂模型自己的生成结果。
- **`<sos>` 与 `<eos>`**：序列的开始/结束标记，让解码器学会「何时开始说话、何时闭嘴」，测试阶段靠 `<eos>` 判定生成终止。
- **编码器 output 与 hidden 的分工**：hidden 传给解码器当初始状态；output（每个时间步的编码）本章没用上，是留给下一章注意力机制的接口。
- **BLEU**：机器翻译的常用质量指标，比较机器译文与人工译文的 N-Gram 匹配精度，并加简短惩罚防止「翻得越短分越高」。
- **固定向量瓶颈**：整句输入被压进一个固定长度的向量，序列一长信息就挤丢了——这个缺陷正是引入注意力机制的直接动机。

## 第5章 见微知著开慧眼：引入注意力机制

**本章解决什么问题**：RNN 版 Seq2Seq 把整句输入压成一个固定向量，上下文信息容易丢失——本章引入注意力机制，让解码器按需回看输入序列的不同位置，为下一章彻底抛弃 RNN 的 Transformer 打下地基。

### 核心概念
- **注意力机制（Attention）**：处理每个词时，按相关程度给输入序列各个位置分配不同权重，有选择地「关注」重要部分，而不是一口吞下整句话。
- **点积注意力（Dot-Product Attention）**：用向量点积当相似度打分——x1 的每个位置和 x2 的每个位置两两打分，归一化后对 x2 加权求和，得到「关注了 x2 之后的新 x1」。
- **原始权重与注意力权重**：点积算出来的叫相似度得分（原始权重），softmax 归一化后（值在 0~1 之间、每行和为 1）才叫注意力权重，两个术语要分清。
- **softmax 归一化**：把一组任意数值变成一个概率分布，$softmax(x_i)=\frac{e^{x_i}}{\sum_{j=1}^{n}e^{x_j}}$（$x_i$ 为待转换的第 i 个得分；分母为所有得分的指数和）。
- **缩放点积注意力（Scaled Dot-Product Attention）**：softmax 之前先把得分除以 $\sqrt{d_k}$，防止特征维度大时点积过大、softmax 落入饱和区导致梯度消失，$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$（$Q$ 为查询矩阵；$K$ 为键矩阵；$V$ 为值矩阵；$d_k$ 为键向量维度）。
- **编码器-解码器注意力**：把点积注意力装进 Seq2Seq——解码器隐藏状态当 Q（即 x1），编码器隐藏状态当 K 和 V（即 x2），每个时间步生成一个上下文向量辅助预测。
- **Q/K/V**：Q 是「我想找什么」，K 是「每个位置的标签」，V 是「每个位置实际携带的信息」；算 Q 与 K 的相似度得权重，再对 V 加权求和。Transformer 中三者由同一输入经不同线性变换得到。
- **自注意力（Self-Attention）**：序列自己看自己，每个 token 的表示都融入了全序列的上下文，词嵌入的内涵由此被大幅延展。
- **多头自注意力（Multi-Head Attention）**：把 Q/K/V 投影到多个子空间，并行做注意力再拼接，从不同角度捕捉特征。
- **注意力掩码（Attention Mask）**：把不该看的位置的分数压成极小值（约 -1e9），softmax 后权重趋近 0；分填充掩码（屏蔽 `<pad>`）和后续掩码（屏蔽未来信息，下一章展开）。
- **注意力家族**：还有加性（Bahdanau）、全局/局部、自适应、分层、因果等变体，可按任务组合选用。

| 缩放点积注意力（增加除以 $\sqrt{d_k}$ 一步） | 缩放让 softmax 工作在平缓区，权重分布不再极端，缓解梯度消失 |

## 第6章 层峦叠翠上青天：搭建GPT核心组件Transformer

**本章解决什么问题**：在第5章注意力组件的基础上，彻底甩掉 RNN，从零搭建完整的 Transformer 编码器-解码器并跑通中译英任务——这是 GPT 的内核，也是全书承上启下的关键一跃。

### 核心概念
- **Transformer**：2017 年《Attention is All You Need》提出，完全抛弃循环结构、只靠注意力并行处理序列，解决 RNN 长距离依赖弱、难以并行的痛点；BERT、GPT 都由它衍生。
- **编码器-解码器分工**：编码器把源序列提取成一组富含上下文的表示，解码器结合自身输入（右移后的目标序列）与编码器输出生成目标序列。
- **位置编码（Positional Encoding）**：并行计算天生感知不到词序，用不同频率的正弦余弦为每个位置生成固定向量并与词嵌入相加，$PE(pos,2i)=\sin(\frac{pos}{10000^{2i/d_{model}}})$，$PE(pos,2i+1)=\cos(\frac{pos}{10000^{2i/d_{model}}})$（$pos$ 为词在序列中的位置；$i$ 为维度下标；$d_{model}$ 为词嵌入维度；偶数维取 sin、奇数维取 cos）。
- **多头自注意力（Multi-Head Attention）**：每个头在不同子空间各算一次缩放点积注意力，拼接后统一投影，$MultiHead(Q,K,V)=Concat(head_1,\dots,head_h)W^O$，其中 $head_i=Attention(QW_i^Q,KW_i^K,VW_i^V)$（$h$ 为头数，本章取 8；$W_i^Q$/$W_i^K$/$W_i^V$ 为各头的投影矩阵；$W^O$ 为拼接后的输出投影）。
- **残差连接（Residual Connection）**：子层输出与输入直接相加，让信息「抄近道」传向深层，缓解梯度消失、加快训练。
- **层归一化（LayerNorm）**：对每个 token 的特征向量做归一化，稳定各层输入分布、允许更大学习率；与残差连接合称 Add & Norm。
- **逐位置前馈网络（Position-wise FFN）**：对每个 token 独立执行「升维 → ReLU → 降维」的非线性变换；实现上用 kernel_size=1 的一维卷积代替全连接层，各位置共享权重、节省参数。
- **填充掩码（Padding Mask）**：批量训练时把 `<pad>` 位置的注意力分数置为 -1e9，softmax 后权重趋近 0，模型只关注真实 token。
- **后续掩码/因果掩码（Subsequent / Causal Mask）**：用上三角矩阵遮住当前位置之后的 token，保证预测时只能看到当前位置及之前的信息，这是生成式模型的「单向」铁律。
- **向右位移（Shifted Right）**：解码器输入是目标序列右移一位、句首补 `<sos>`，配合后续掩码，让模型学会「看前文、猜下一个词」。
- **编码器-解码器注意力**：解码器的第二个注意力单元——Q 来自解码器上一层输出，K/V 来自编码器输出，让生成端随时回看源序列。
- **三种注意力的掩码配置**：编码器自注意力只用填充掩码；解码器自注意力填充+后续掩码都要；编码器-解码器注意力只用填充掩码。
- **输出头（Projection + Softmax）**：解码器输出经线性层映射到词表大小、softmax 得到每个位置的概率分布；换下游任务只需换头和损失函数（翻译/分类/问答/NER 各有做法）。

## 第7章 芳林新叶催陈叶：训练出你的简版生成式GPT

**本章解决什么问题**：站在上一章 Transformer 解码器之上，亲手搭出仅用解码器的生成式 GPT，并用真实语料 WikiText2 训练出 Wiki-GPT，为下一章微调 ChatGPT 准备好基础模型。

### 核心概念
- **BERT 与 GPT 之争**：BERT 是双向的编码器架构、靠「完形填空」（MLM 掩码语言模型）预训练，擅长理解类任务；GPT 是单向的解码器架构、靠「预测下一个词」预训练，擅长生成类任务——两者恰好各取 Transformer 的「一半」。
- **自回归（Autoregressive）**：像竹子节节高，每个新预测值都建立在已生成的值之上，GPT 的生成机制就是不断「看前文、猜下一个词」。
- **自回归的两副面孔**：训练时靠「输入右移一位」构造目标序列加后续掩码，并行学完整个序列；推理时才真正逐词生成，把新词追加进输入再预测下一个，直到 `<eos>`。
  - 语言模型的因子分解：$P(w_1, w_2, \dots, w_T) = \prod_{t=1}^{T} P(w_t \mid w_1, \dots, w_{t-1})$
  - 符号速查：$w_t$ 为第 $t$ 个词，$T$ 为句子长度，等式左边是整句话的概率，右边把它拆成一串「已知前文猜下一个词」的乘积——这正是 GPT 的训练目标。
- **后续注意力掩码（Subsequent Mask）**：上三角矩阵把「未来位置」的注意力权重压成极小值，让每个位置只能看当前及之前的信息，防止模型偷看答案。
- **贪婪搜索（Greedy Search）**：每步只选概率最高的那个词，计算快，但容易陷入局部最优，出现 token 反复、废话循环。
- **集束搜索（Beam Search）**：每步保留按累计得分排名的前 K 个候选序列（K 为集束宽度），在全局与局部间做更好的权衡，代价是计算量更大。
- **Decoder-only 结构**：GPT = 词嵌入 + 位置编码 + N 层解码器层（每层只有一个多头自注意力 + 前馈网络，各配残差连接和 LayerNorm）+ 投影层输出 logits；省掉了编码器和交叉注意力，比 Transformer 解码器更简洁、训练更快。
- **训练数据「右移一位」**：同一个句子切两刀，`seq[:-1]` 当输入、`seq[1:]` 当目标，一位之差就把「下一个词」的标签全造好了。
- **PyTorch 数据流水线**：Dataset（实现 `__init__`/`__len__`/`__getitem__`）管样本，DataLoader 管分批，collate_fn 加 pad_sequence 把不等长序列补齐成整齐张量。
- **验证集与最优模型保存**：数据够大时留出验证集，每轮结束算验证损失，把历史最低的那份权重用 `torch.save` 存下来（`.pt` 与 `.pth` 只是扩展名习惯，无本质区别）。
- **忽略填充位的损失**：`CrossEntropyLoss(ignore_index=<pad>)` 让补齐用的填充 token 不参与损失计算，不干扰真实语言的学习。

## 第8章 流水后波推前波：ChatGPT基于人类反馈的强化学习

**本章解决什么问题**：接住上一章的 Wiki-GPT，走完「预训练 + 微调」范式直至 RLHF 三阶段，讲清并简化实现从 GPT 到 ChatGPT 的最后一公里。

### 核心概念
- **GPT 家族演进**：GPT（2018，1.17 亿参数）→ GPT-2（15 亿）→ GPT-3（1750 亿，零样本/少样本免微调）→ 基于 GPT-3.5 的 ChatGPT 与 InstructGPT，模型越大能吃下的上下文越长、生成质量越高。
- **伸缩定律（Scaling Law）**：模型性能随规模增长而提升，参数超过约 600 亿后推理能力开始涌现——这是「堆参数」路线的理论依据。
- **指令调优（Instruction Tuning）**：用对话、指令类数据微调预训练模型，让它更懂对话的上下文、情感和逻辑。
- **对齐（Alignment）**：让 AI 的目标与人类价值观一致，加入安全与合规约束，避免产生危害性回答。
- **预训练 + 微调范式**：预训练在海量无标注文本上学通用语言规律，微调用小数据适配具体任务，数据和算力都省。
- **分词器与词汇表一致性**：微调必须沿用预训练时的分词器和词汇表，否则词的索引对不上号，预训练学到的知识就传不过去。
- **冻结底层（Freeze Layers）**：微调数据少或与预训练数据相似时，冻结底层只更新上层，保住底层通用特征并防过拟合。
- **Hugging Face Transformers**：开源预训练模型库，GPT2LMHeadModel 与 GPT2Tokenizer 必须配套使用；GPT-2 用 `<|endoftext|>` 兼任起止符，填充符需手工指定；训练时关心的主要是返回对象里的 logits。
- **RLHF 三阶段循环**：SFT（监督微调得到初始模型）→ RM（用人工排序训练奖励模型，代替人类打分）→ PPO（拿 RM 的分数当奖励继续优化模型），三步循环迭代、越滚越强。
- **强化学习六要素**：智能体、环境、状态、行动、策略、奖励——用「飞小鸟躲水管」类比；在 ChatGPT 里智能体是模型、行动是回答、奖励来自人类反馈。
- **PPO（近端策略优化）**：OpenAI 提出的策略梯度算法，用 Clip 机制限制每次策略更新的幅度，避免一步迈太大，稳定性和样本效率都好。
- **奖励加权损失**：把人类评分变成可计算的奖励，再拿奖励去给交叉熵损失加权：$\mathcal{L}_{w} = \frac{1}{N}\sum_{i=1}^{N} \mathcal{L}_i \cdot (1 - r_i)$
  - 符号速查：$\mathcal{L}_i$ 为第 $i$ 个样本的交叉熵损失，$r_i$ 为该样本的奖励（0 到 1），$N$ 为样本数；奖励越高权重越小，等于让模型把学习火力集中在高分管案上。

|---|---|

## 第9章 生生不息的循环：使用强大的GPT-4 API

**本章解决什么问题**：全书收官，视角从「自己造模型」切换到「调用大模型」——用 OpenAI 的 GPT-4 API 十几行代码搭出聊天机器人，并俯瞰周边开发生态。

### 核心概念
- **OpenAI API**：每个模型都有专属 API，按调用计费（新账号有 18 美元额度），并受速率限制（每分钟请求数、token 数等）；API Key 只在创建时完整可见，须妥善保存、绝不外泄。
- **ChatCompletion 调用模式**：传 `model` + `messages` 即可对话；`role: system` 的第一条消息给 GPT 设定角色人设，之后循环追加 `user` 消息即可维持多轮上下文。
- **生成控制参数**：Temperature（越高越随机、越低越确定）、最大 token 数、存在惩罚（鼓励谈新话题）、频率惩罚（抑制逐字重复）。
- **LLM 应用开发生态**：LangChain 用链、代理、提示模板封装模型调用，LlamaIndex 负责把自定义数据接入大模型；上层还有 Microsoft 365 Copilot、各类插件与 AutoGPT 等应用形态。

## 后记 莫等闲，白了少年头

**本章解决什么问题**：全书技术线索的收官回顾，并回答「AI 大时代里人该往哪走」。

### 核心概念
- **NLP 技术演进主线**：从 N-Gram、词袋模型的词频统计，到 Word2Vec 词向量、NPLM 与 RNN/TextCNN 的深度学习，再到 Seq2Seq 编码器-解码器、Attention 机制、Transformer 自注意力，最终由 BERT（双向理解）与 GPT（单向生成）把预训练大模型推向「通用人工智能雏形」。
- **非线性突破**：科技进步不是匀速直线，ChatGPT 属于「奇迹式涌现」的节点，如同登月重新划定了人类的认知边界。
- **AI 替代任务而非人的独特性**：文书、数据分析等可自动化，但创造力与想象力、社交与人际关系、技术与编程、判断与决策这四类能力仍是人类不可替代的优势。
- **应对姿势**：借 AI 更深入地学习每个领域，而不是坐享其成——时代巨变既是挑战也是机遇，别等闲白了少年头。
